# ADR-20260524 wave211 — v0.75.0 Phase 44 close

## Bağlam

Phase 44, marathon'un 47. minor release'i. Material katmanına PBR
parametre struct'ı ve asset katmanına LRU-style memory budget tracker
eklendi.

## Karar

### 44.A — `cd/material/PbrParams.hpp` (+ CMake dep)
glTF 2.0 metallic/roughness + Disney 2012 base workflow için tek struct:
- `PbrFactors` (48 byte, std140-packed): albedo[4] + emissive[3] +
  metallic + roughness + occlusion + normal_scale + _pad.
- `PbrTextures`: 5 × AssetId slot (albedo, metallic_roughness, normal,
  occlusion, emissive).
- Helper'lar: `is_opaque(f)` (alpha ≥ 0.999), `is_emissive(f)` (any
  channel > 0).

CMake değişikliği: `cd::material` artık `cd::asset` PUBLIC_DEPS
(PbrParams.hpp AssetId referansı). DAG'da cycle yok — asset üst
katmanda (cd::asset → core/io/vfs), material aşağıda.

### 44.B — `cd/asset/MemoryCache.hpp`
LRU asset cache tracker:
- `touch(id, bytes)` — entry ekler/yeniler, monotonic `clock_++`
  ile timestamp.
- `forget(id)` — entry siler, total_bytes düşer.
- `victims(release_bytes)` — sıralı oldest-first liste döner;
  cumulative ≥ release_bytes olunca durur.

Cache **owner değil**; AssetRegistry sahibidir, bu sadece eviction
policy önerir.

### Test hygiene (ders pekiştirme)
Phase 34/41'de keşfedilen anon-namespace include trap, test_material.cpp'de
bir kez daha karşımıza çıktı: `cd/material/PbrParams.hpp` transitively
`cd/asset/AssetId.hpp` include ediyor, AssetId.hpp `std::hash<AssetId>`
özelleştirmesi yapıyor — bu specialization ile ::std namespace açılışı
anon ns içinde gerçekleşemez. Fix yine: anon ns'i kapat, sonra include
+ tests global scope'ta.

## Reddedilen alternatifler

- **PbrParams'a clear-coat / sheen / transmission**: tam Khronos
  KHR_materials_clearcoat / KHR_materials_sheen extension'ı önemli
  ama tek bir PbrParams struct'a sığdırmak std140 layout'u şişirir.
  Sub-struct olarak ileride ek extensions table.
- **MemoryCache priority queue ile O(log n)**: 100 asset için
  sort O(n log n) yeterli; gerçek hot-path zaten eviction sırasında
  değil access sırasında (touch O(1)).
