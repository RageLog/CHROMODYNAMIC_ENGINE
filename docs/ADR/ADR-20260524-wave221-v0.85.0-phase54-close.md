## Karar

### 54.A — `cd/physics/SweepResult.hpp`
Continuous collision detection için:
- `SweepResult { hit, toi, point, normal }` data type.
- `sweep_sphere_aabb(start, dir, radius, aabb)` — Minkowski-sum trick:
  AABB'yi `radius` ile genişlet, sphere center'ından `dir` boyunca
  expanded box'a ray-cast. TOI ∈ [0, 1], aksi takdirde no-hit.
- Normal estimation: hit noktasının en yakın expanded-AABB yüzeyine
  bakılır (6-axis test).

Character controller / projectile path için temel CCD primitive.

### 54.B — `cd/concurrency/ParallelFor.hpp`
`parallel_for(begin, end, fn, worker_count=0)`:
- `worker_count == 0` → `std::thread::hardware_concurrency()`.
- Aralığı eşit chunks'a böl, her thread bir slice çalıştır.
- Tüm thread'ler join.

Trade-off doc'ta açık: ThreadPool hot-path, ParallelFor occasional
bulk work (asset cooking, batch import, content validate). Pool
setup maliyeti yok.

  ImmediateContactReturnsTOIZero — 3 case.

## Reddedilen alternatifler

- **GJK + Conservative Advancement (true CCD)**: ileride mesh-mesh
  sweep için gerekli, sphere-AABB için Minkowski expand yeterli ve
  closed-form.
- **`std::execution::par` algorithms**: standart library implementation
  vendor'a göre değişiyor; sade `std::thread` + chunk daha öngörülebilir.
