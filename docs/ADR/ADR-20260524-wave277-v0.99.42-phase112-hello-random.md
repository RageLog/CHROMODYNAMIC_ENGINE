# ADR-20260524 / Wave 277 / v0.99.42 / Phase 112 — hello_random Distribution Viz

## Status
Accepted — 2026-05-24

## Context

`cd::math::Random` (PCG32, Phase 24.A) shipped without an end-to-end
demo that verified the PRNG output looked plausible at a glance.
Existing unit tests check `next_u32()` produces non-zero values but
don't visualize distributions.

## Decision

New `samples/hello_random/` console sample:

1. **Uniform [0,1) histogram** — 100k samples binned into 50
   buckets, ASCII bar chart per bin. Expected mean ≈ 0.5,
   variance ≈ 1/12 ≈ 0.0833.
2. **Standard normal via Box-Muller** — 100k samples, 60 buckets
   over ±3σ. Expected mean ≈ 0, variance ≈ 1.
3. **Stream decorrelation** — Pearson correlation of two
   independently-seeded PCG32 streams (50k samples each). Should
   round near zero (~10⁻³ at this sample count).
4. **Determinism** — two same-seeded instances must produce the
   same 1024-u32 stream byte-for-byte.

Output (verified on a sample run):
- Uniform mean=0.500 +/- 0.01, variance ≈ 0.083
- Normal mean=-0.0015, var=0.9943, std=0.9971
- Correlation 0.000876
- Determinism: YES

## Rejected alternatives

- **Plot via matplotlib / pyplot.** Adds a Python dependency and
  output-format coupling. ASCII histogram is portable and good
  enough for a smoke test.
- **GPU compute-shader RNG verification.** Out of scope — the
  CPU PRNG is the contract being verified here.

## Consequences

- Sample count grows from 49 → 50.
- DEMO_REEL.md gains a Phase 112 entry candidate (next polish pass).
- Future RNG additions (xorshift64, Wyhash, etc.) can plug into the
  same harness.

## Validation

```
cmake --build --preset llvm-win-debug --target cd_sample_hello_random
./build/llvm-win-base/bin/Debug/hello_random.exe
```

All assertions (uniform mean, normal mean/var, correlation, byte-
identical stream) within expected tolerances.
