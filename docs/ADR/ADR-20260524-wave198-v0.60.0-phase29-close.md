# ADR-20260524 wave198 — v0.60.0 Phase 29 close

## Bağlam

Phase 28'de math'e Vec2 yardımcıları kapandı. Phase 29 iki küçük ama
yaygın gerekli primitive ekler:

1. **`cd/core/BitOps.hpp`** — `<bit>` (C++20) etrafında constexpr sarmalayıcılar.
   Allocator, hash table sizing, ve SIMD lane mask çağrı sitelerinde
   tekrar tekrar `(x + a - 1) & ~(a - 1)` yazılmasının önüne geçer.
2. **`cd/net/PacketHeader.hpp`** — 8-byte versioned UDP preamble.
   Magic `'CDNT'` + protocol version + opcode + payload length. Yabancı
   trafiği reddetmek, sürüm sürüklenmesini tespit etmek, ve payload'u
   opcode'a göre yönlendirmek için gereken minimum kontrat. ChannelMux
   ileride bu header'ı zaten varsayıyor olabilir; şimdi ortak tanımı
   tek yere koyuyoruz.

## Karar (Phase 29.A — BitOps, Phase 29.B — PacketHeader)

### 29.A BitOps
- `popcount`, `count_lzero`, `count_tzero` — `<bit>` proxy.
- `is_pow2(x)` — `x != 0 && (x & (x-1)) == 0`.
- `next_pow2(x)` — `std::bit_ceil` ama `0 → 1` özel kasası.
- `align_up(x, a)` / `align_down(x, a)` — `a` pow2 varsayar
  (branch-free, hot path).

### 29.B PacketHeader
- `kPacketMagic = 0x434E4454u` ('CDNT' ascii LE).
- `kPacketVersion = 1u`.
- `Opcode` enum class (uint8_t): Invalid, Handshake, Heartbeat,
  Reliable, Unreliable, Ack, Disconnect.
- `static_assert(sizeof(PacketHeader) == 8)` — wire compat.
- `is_valid(h)` — magic + version + non-Invalid opcode.

## Reddedilen alternatifler

- **BitOps'u math katmanına koymak**: bit ops semantik olarak math
  değil — pointer alignment, allocator sizing core sorumluluğu.
- **PacketHeader içinde checksum/crc**: ChannelMux/Retransmit
  katmanlarının zaten kendi sequence + ack şemaları var; CRC
  duplicate iş olur. Ileride MTU'nun altında olduğunda eklenir.
- **Big-endian destek**: Roadmap'imizde BE target yok (Intel/ARM
  hep LE). Wire LE — memcpy ile in/out, byte-swap shim eklemiyoruz.
