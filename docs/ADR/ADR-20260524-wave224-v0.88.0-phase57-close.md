# ADR-20260524 wave224 — v0.88.0 Phase 57 close

## Bağlam

Phase 57, marathon'un 60. minor release'i. UI progress state machine
+ concurrency MPSC channel + uzun süredir gizli kalmış ad-collision
fix'i.

## Karar

### 57.A — `cd/ui/ProgressBar.hpp`
Headless progress state:
- `set_total(n)` / `tick(units=1)` / `set_done(d)` (clamp).
- `progress()` → float ∈ [0, 1], `is_complete()` → bool.
- `done()` / `total()` getters, `reset()`.

Loading screen, asset baking progress, streaming pipeline'ında
caller'ın "ne kadar bitti" mantığını tutar. Render rendering-agnostic.

### 57.B — `cd/concurrency/Channel.hpp`
Bounded MPSC queue:
- `send/try_send` (block / nonblock), `receive/try_receive`,
  `close()` waiting receiver'ları nullopt ile uyandırır.
- `std::mutex` + `std::condition_variable` ile correctness-first.

Engine içi cross-thread mesajlaşma (asset loader → main thread,
log producer → log sink) için. Lock-free MPSC ThreadPool deque'da
zaten var; bu primitive "blocking semantik" ihtiyacı için.

### 57.C — Bug fix: hidden `cd::ui::Rect` collision
Phase 32'de eklenen `Anchor.hpp` `cd::ui::Rect` adıyla bir struct
tanımlamıştı; Widget.hpp da `cd::ui::Rect` (farklı float-based) struct
sahibiydi. Tests'in anon-namespace içine Anchor include edildiği için
ad çakışması nested ns'de saklanmıştı.

Phase 57'de tüm includes file-top'a taşınınca ODR violation patladı.
Fix: `Anchor.hpp` içindeki `Rect` → `IntRect` rename. Anchor testleri
güncellendi (`cd::ui::Rect parent` → `cd::ui::IntRect parent`).

Bu, "anon-ns include hijacking" pattern'inin gizlediği latent bug'ın
ilk somut örneği — file-top include disiplini bugün üç şeyi
düzeltiyor.

## Test

- ProgressBar: EmptyTotalReturnsZeroProgress, TickAdvancesProgress,
  TickClampsToTotal, ResetReturnsToZero, SetDoneClamps — 5 case.
- Channel: TrySendThenTryReceive, TrySendFullReturnsFalse,
  ProducerConsumerRoundTrip (10-item producer thread + main consumer,
  sum=45 invariant), CloseUnblocksReceiver — 4 case.

`ctest --preset ninja-debug` → **58/58 PASS**.

## Reddedilen alternatifler

- **`cd::ui::Rect` (Widget) vs `IntRect` (Anchor) birleştirmek**:
  Widget.hpp float-based, Anchor int-based — farklı kullanım için
  farklı tipler. Birleştirmek bir API breaking change olur.
- **Channel için lock-free MPMC**: hot loops için doğru ama design
  scope büyük; semaphore + circular buffer ile ileride.
