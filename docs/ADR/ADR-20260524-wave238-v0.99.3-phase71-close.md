## Bağlam

Phase 71, marathon'un 74. tag'i (patch level). Net RLE codec + core
fixed-size pool allocator.

## Karar

### 71.A — `cd/net/RleCodec.hpp`
Klasik run-length encoding:
- `rle_encode(bytes) → (count, value)*` records.
- `rle_decode(rle) → bytes`.
- Run uzunluğu 255'te split (uint8 count limit).
- Empty input → empty output, well-defined.

Sparse entity state delta, terrain heightmap stream, save-file
sıkıştırma için MVP.

### 71.B — `cd/core/PoolAllocator.hpp`
O(1) fixed-block pool:
- Free-list threaded through unused blocks (next-pointer ilk
  sizeof(void*) byte'ında).
- `block_size < sizeof(void*)` → clamp.
- `allocate()` exhaustion → nullptr.
- `used_count` / `free_count` query.

ECS sparse-set chunk storage, particle pool, command-list scratch
slot için. FrameAllocator (Phase 25) coarse arena, PoolAllocator
fine-grained per-block free.
