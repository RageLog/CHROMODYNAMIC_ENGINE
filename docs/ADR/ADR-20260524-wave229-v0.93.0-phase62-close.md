## Bağlam

Phase 62, marathon'un 65. minor release'i. Rigid-body mass + diagonal

## Karar

### 62.A — `cd/physics/InertiaTensor.hpp`
- `RigidBodyMass { mass, inertia, inv_mass, inv_inertia }` —
  solver doğrudan tüketir.
- Closed-form factory'ler:
  - `solid_sphere(m, r)` — I = (2/5) m r²
  - `solid_box(m, x, y, z)` — Ixx = (1/12) m (y² + z²) vs.
  - `solid_cylinder_y(m, r, h)` — Y-axis symmetry varsayar.
  - `kinematic()` — all-zero (infinite mass solver convention).
- `inv_or_zero(x)` helper: x==0 ise 0 (kinematic body için doğru
  fallback).

Inertia tensor genel için 3×3 ama temel primitive'lerin lokal frame'i
diagonal — `Vec3f` storage cache-friendly + GPU-uniform-friendly.

### 62.B — `cd/camera/ViewportInfo.hpp`
- `ViewportInfo { x, y, width, height }` int piksel rect.
- `aspect(v)` — zero-height safe fallback.
- `screen_to_ndc(v, px, py, &xn, &yn)` — Vulkan convention (top-left
  pixel → (-1, 1) NDC, y-flipped).
- `ndc_to_screen` — inverse round-trip.

ImGui picking, editor 3D viewport mouse → ray cast, debug overlay
positioning için.

## Reddedilen alternatifler

- **3×3 inertia tensor**: oriented body rotation için doğru ama
  solver hot-path frame transformation gerektirir. Local diagonal +
  per-frame `rotation * inertia * rotationᵀ` ileride.
- **ViewportInfo'a DPI scale**: editor multi-monitor için ileride;
  şu an raw pixel yeterli.
