# ADR-20260524 wave220 — v0.84.0 Phase 53 close

## Bağlam

Phase 53, marathon'un 56. minor release'i. Net katmanına byte-level
delta encoder + camera katmanına physical-lens parametre primitive'leri.

## Karar

### 53.A — `cd/net/DeltaWriter.hpp`
Byte-bazlı delta encoder:
- `write_delta(baseline, current)` → `vector<byte>` (offset,value)
  stream'i. Wire format: `u16 changed_count` + N × `(u16 offset, u8
  value)`. Break-even N < (size-2)/3.
- `apply_delta(target, delta)` → baseline'a apply, malformed delta
  rejection.

ECS state replication path'inin reliable channel ucu için: 32-byte
entity state'inin ≤4 byte değiştiğinde ~%56 bandwidth tasarrufu.

### 53.B — `cd/camera/Lens.hpp`
Photographic lens parameter struct:
- `Lens { focal_length_mm, aperture, focus_distance_m }`.
- `fov_y_for(sensor_height_mm=24)` — full-frame 36×24 sensör formülü.
- `apply_to(camera)` — Camera.fov_y'i hesaplanan değere yazar.
- Factory'ler: `lens_wide()` (24mm), `lens_standard()` (50mm),
  `lens_portrait()` (85mm), `lens_telephoto()` (200mm).

Cinematographer / level artist mental model: "50mm" daha doğal
"fov_y=1.0 radian"'dan.

## Test

- DeltaWriter: EmptyChangesProducesEmptyMarker, RoundTripThroughApply
  (32-byte payload, 3 değişen byte), MismatchedSizesProduceEmptyDelta,
  TruncatedDeltaRejected — 4 case.
- Lens: StandardLensYieldsReasonableFov (~26°), WideLensHasLargerFovThanTelephoto,
  ApplyToCameraUpdatesFovY, ZeroFocalLengthReturnsSafeFallback — 4 case.

`ctest --preset ninja-debug` → **58/58 PASS**.

## Reddedilen alternatifler

- **Delta için RLE veya XOR-then-rle**: byte-level (offset, value)
  şema simple + good-enough for 32-byte payloads. XOR-RLE patterned
  changes (oyuncu pos delta) için daha kompakt olur — gelecek wave.
- **Lens'in DoF (depth-of-field) hesabını da içermesi**: aperture
  field'ı struct'ta var ama DOF post-process'in işi; primitive
  data-only.
