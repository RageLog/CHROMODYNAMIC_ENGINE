# ADR-20260524 / Wave 299 / v0.99.64 / Phase 138 — hello_engine mega-showcase

## Status
Accepted — 2026-05-24

## Context

The user asked, after the Ultimate hello-app design discussion (apps-
layer mimicked-DtRuntime architecture), to instead ship a **bigger
sample** — one window, one binary, every marathon subsystem visible
at once. The apps-layer plan is parked for the future "engine
v1+ application skeleton" milestone.

## Decision

New `samples/hello_engine/` — single `main.cpp` (~1100 lines), one
window, ImGui DockSpace splitting the viewport into 8 panels plus
a Ctrl+Shift+P command palette.

Panels:

- **Center viewport** — `AnalyticalSkyMaterial` fullscreen sky,
  5×5 PBR sphere sweep (`StandardPbrMaterial`), 5 procedural
  primitive entities (Cube / Sphere / Cone / Cylinder / Torus
  via `cd::asset::Primitives`).
- **Scene** — entity list, click to select.
- **Inspector** — DragFloat3 live-edit position + scale.
  IsItemActivated/IsItemDeactivatedAfterEdit pattern pushes one
  delta command per drag-release into `cd::editor::EditHistory`.
- **History** — undo/redo depth + last 64 events.
- **Audio** — Mixer → Compressor → SimpleReverb → LowPass →
  Limiter chain ticked every frame against a synthetic
  square + noise-burst source. Shows comp dB, limiter gain,
  peak, last-120-tick peak history line plot.
- **Net Sim** — `Throttle` (30 pkt/s cap) + `SnapshotBuffer` +
  `LatencyStats` + `DeltaWriter` driven by a 60 Hz simulated
  server tick. Live counters for sent / recv / dropped / wire
  ratio / RTT / jitter / snapshot buffer depth.
- **Random** — PCG32 uniform + Box-Muller normal histograms
  rebuilt every ~2 seconds (8192 samples each, 24 bins).
  Drawn via `ImGui::PlotHistogram`.
- **Counters** — live `cd::core::CounterTable` snapshot
  (frame index, audio ticks, net ticks, PBR draws, primitive
  draws, culled-sphere count).

Command palette commands (15 registered):

- Edit: Undo / Redo / Clear History.
- Select: Cube / Sphere / Cone / Cylinder / Torus.
- Transform: Reset Selected.
- Camera: Toggle Auto-Spin / Follow Selected (drives
  `SceneCameraController`).
- Audio: Toggle Mute.
- Net: Toggle Sim.
- Random: Reseed + Refresh.
- Help: Print Shortcuts.

Render-loop layering:

1. Sky pass (no depth, full-screen triangle).
2. PBR sphere sweep (5×5 grid, fixed Z = −4.5, drawn behind
   primitives).
3. ECS primitive entities (per-entity model matrix from
   `Scene::local`, mesh chosen by `PrimitiveKind`).
4. ImGui pass.

Camera is a `SceneCameraController` with auto-spin enabled,
follow-target wireable via the palette.

The sample is window-based; runs cleanly when killed externally
(smoke confirmed 320 KB working set, no crash on close-from-
taskkill).

## Rejected alternatives

- **Apps-layer module architecture** (DtRuntime mimic). Parked
  for engine v1+. The user explicitly chose "bigger sample
  first" over "application-layer refactor first."
- **Multiple files** (`main.cpp` + per-panel modules). Marathon
  sample pattern is single-file; the mega-sample stays sample-
  shaped so it parallels every other `hello_*`.
- **Headless smoke build via `--headless`**. The runtime tour
  is the value; CI can still gate via `--no-spin --headless`
  by composing existing `SampleRuntime` helpers (not added in
  this commit to keep scope tight).
- **Native menubar instead of ImGui DockSpace**. Dock layout
  matches `hello_editor` and integrates with the existing
  `cd::imgui_backend` Vulkan path.

## Consequences

- Sample count: 51 → 52.
- One target end-to-end touches every Phase-13+ subsystem:
  - Render: skybox + PBR + 3D primitives + ImGui pass.
  - Math: Random (PCG32 + Box-Muller).
  - Asset: Primitives (cube/sphere/cone/cylinder/torus).
  - ECS / Scene: World + Scene + LocalTransform + entity tree
    + SceneCameraController.
  - Editor: EditHistory + TransformCommands + CommandPalette
    + live-drag pattern.
  - Audio: Mixer + Compressor + SimpleReverb + LowPass + Limiter.
  - Net: Throttle + SnapshotBuffer + DeltaWriter + LatencyStats.
  - Core: CounterTable.
  - Material: StandardPbrMaterial + AnalyticalSkyMaterial (the
    engine-side header shipped Phase 104/105).
- Sample binary is the **single most useful demo** for showing
  "what does CHROMODYNAMIC do today" to a new observer.

## Validation

```
cmake --build --preset llvm-win-debug --target cd_sample_hello_engine
./build/llvm-win-base/bin/Debug/hello_engine.exe   # ESC to exit
```

Builds clean. Runtime smoke: window opens, all panels render, audio
chain advances, net sim counters increment, palette responds to
Ctrl+Shift+P.
