## Bağlam

PBR integration" — Phase 8 routing tablosunun ilk item'ı, kullanıcının
"kolaydan zora" sırasının devamı.

## Reddedilen alternatifler

- **Sprint 10'da Vulkan pipeline wiring'ı bitirmek:** Compute shader
  + descriptor set + vkCmdDispatch + sync gerekiyor. GPU CI runner
  expansion yok; lokalde test edilemez. Algorithm sözleşmesini
  kilitlemek + parity test ile doğrulamak daha temiz; Vulkan bağlama
  iş Phase 8 Sprint 10.b.
- **PBR shader integration paralel olarak:** Fragment shader cluster
  buffer'ı sampling ediyor — bu da Vulkan wiring'in parçası. Aynı
  ertelemeye tabi.
- **GLSL'i shader/Compiler üzerinden CI'da derleyip SPIR-V cache'lemek:**
  cd::shader::CachedCompiler mevcut ama glslang runtime dep; ek
  bağımlılık bu wave için scope dışı. Sprint 10.b ekleyebilir.

## Açık sorular

- **Sprint 10.b (Vulkan pipeline wiring):** Şu an mı yoksa Sprint 11
  candidate'ından sonra mı? Kullanıcı seçecek.
- **glslang runtime dep:** cd::shader var ama runtime'a default değil.
  cluster_assign.comp'u runtime compile etmek mi yoksa offline derleyip
  binary SPIR-V'i resource olarak embed etmek mi? Offline'in CI tracking
  açısından avantajı: shader değişiklikleri SPIR-V hash diff'inden görünür.
- **PBR fragment shader cluster sampling syntax:** GLSL `set 0 binding N`
  layout, mevcut PBR material için ek descriptor set slot gerekiyor.
  Material system ADR'sine update.
