## Karar

### 58.A — `cd/scene/HeightField.hpp`
`width × height` float grid + cell_size + origin. API:
- ctor `(w, h, cell_size=1, origin_x=0, origin_z=0)`.
- `set(x, z, h)` / `get(x, z)` — bounds-check.
- `sample(world_x, world_z)` — bilinear interp, clamp-to-edge.
- `width()` / `height()` / `cell_size()` getters.

Terrain MVP. Editor "import heightmap PNG" path'i bunu hedef alır;
chunked streaming versiyon ileride.

### 58.B — `cd/math/BarycentricInterp.hpp`
`barycentric_interp(a, b, c, u, v, w)` veya
`barycentric_interp(a, b, c, vec3_uvw)` — float, Vec3, Vec2 ne için
istenirse T template parameter.

Triangle barycentric coords (Phase 27.B) ile birlikte: hit noktasında
color/normal/UV pick için tam çift. Mesh picking + render-target
texturing path'inin temel taşı.
