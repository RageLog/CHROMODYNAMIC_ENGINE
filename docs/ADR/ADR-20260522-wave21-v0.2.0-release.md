## Reddedilen alternatifler

- **`v1.0.0` tag:** Çekici ama "production-ready" iddiası için S4.4
  render thread ve performance regression bench (S4.8'in kapanışından
  sonra) gerekli. v0.2.0 dürüst seviye.
- **Aşamalı release per-wave (v0.1.1, v0.1.2, …):** Wave 14-19 ardışık
  commit'ler; her birini tag'lemek noise. Single batch v0.2.0 daha
  net mesaj.
- **`feature/marathon-2026-05-22` branch'ten release:** master ve dev
  zaten "live" branch'ler; ayrı feature branch overhead.

## Sonuçlar

`v0.2.0` annotated git tag, dev branch HEAD (post-Wave 20 deferral
ADR commit) üzerine atılır. Tag message marathon'un kümülatif çıktısını
ve Phase 4 closure ADR'sini referans verir.

GitHub release notes (manuel) için bu ADR taban olarak kullanılabilir.
