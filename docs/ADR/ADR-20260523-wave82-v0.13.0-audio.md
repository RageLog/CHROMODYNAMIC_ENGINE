# ADR-20260523 — Wave 82: v0.13.0 release tag — Phase 7 Sprint 8 (Audio)

## Bağlam

Phase 7 Sprint 8 = Audio trifecta + 3D positional + HRTF-lite kümesi.
Kullanıcının sıralamasının üçüncü item'ı. Sprint 8 wave'leri:

- Wave 77: 3D positional math (ITD + ILD + stereo gains)
- Wave 78: HRTF-lite per-voice mixer (PositionalSource)

- Wave 82 (BU): v0.13.0 closure + Sprint 9 (Forward+) hazırlığı

## Bu sürümde olanlar (delta v0.12.0 → v0.13.0)

### Phase 7 Sprint 8 waves (77-81)

| Wave | Çıktı |
|---|---|
| Wave 77 | cd::audio::Positional — Woodworth ITD (head radius 0.0875 m, c=343 m/s), 6·sin(θ) dB head-shadow ILD, distance attenuation + constant-power azimuth pan → StereoGains. ListenerPose {position, forward, up} captures orientation. 8 unit tests. |
| Wave 78 | cd::audio::PositionalSource — stateful per-voice mixer; two ring-buffer delay lines (one per ear) sized at prime() time for max ITD; process(mono_in, listener, source_pos, stereo_out) applies cues block-by-block. Audio-render-thread safe after prime (no alloc, no locks). 5 unit tests. |
| Wave 79 | Real CoreAudio AudioUnit DefaultOutput backend on __APPLE__. OS-driven render callback mixes voices, lock-free per-frame. Frameworks linked: AudioUnit + AudioToolbox + CoreAudio + CoreFoundation. |
| Wave 80 | Real ALSA snd_pcm backend on __linux__. Dedicated render thread + snd_pcm_writei loop with snd_pcm_recover on XRUN. libasound linked via find_library. |
| Wave 81 | samples/hello_positional_audio — orbital pan demo. 440 Hz mono sine, source orbits listener 360° over 0.5 s, prints L/R RMS per quadrant. Verified: Q1+Q2 R-dominant, Q3+Q4 L-dominant, full-orbit symmetric to 0.2 %. |

  Windows host'tan __APPLE__ ve __linux__ kod yolları sadece compile

  durum devam edecek.

  iniş yaptı; Sprint 8 sadece kardeş backend'leri eşitledi.

## Açık sorular

* **Multi-channel (>2) support:** Mevcut backends stereo'ya
  normalize ediyor. 5.1 / 7.1 surround Sprint 8+ candidate.
* **HRTF dataset embed:** Full HRTF (CIPIC sample 21 vs. MIT KEMAR)
  binary'ye gömme + lookup tablosu. ~200 KB ek footprint; render
  callback'ten erişilebilir, runtime ek alloc yok.
* **3D positional sample with playback:** hello_positional_audio
  şu an WAV/audio output etmiyor. Native backend + PositionalSource
  birleştirilen ikinci sample Sprint 8+ candidate.
