## Karar

### Patch-level versioning kuralı
`v1.0.0` minor bump'i user'ın imzasına saklı. Marathon yeni primitive
eklemeye devam ediyor ama:
- Yeni functionality patch tag ile yayınlanır (`v0.99.1`, `v0.99.2`, …).
- ABI break gerekirse yine user sign-off bekler (next user session).
- Tüm yeni feature'lar bug-fix değildi — buna rağmen patch level
  tercih edildi çünkü minor 99'u aşmamak istiyoruz.

Convention: marathon kalan tüm phase'ler `v0.99.x` patch level
kullanır; user uyandığında v1.0'a bump için onay verir.
