# ADR-20260524 / Wave 297 / v0.99.62 / Phase 136 — hello_rt sample

## Status
Accepted — 2026-05-24

## Context

Phases 132-135 (this run) wired the complete Vulkan RT chain:
BLAS create + cmd-buffer build (132+133), TLAS create + cmd-buffer
build (127+132+133), RT pipeline interface (134), RT pipeline +
SBT helpers + dispatch_rays impl (135). End-to-end verification
needed a sample that actually drives the full pipeline create +
SBT-handle copy path on a real Vulkan device with RT extensions.

`samples/hello_rt_check` was extended in Phase 128 with create-AS
probes but doesn't reach `create_rt_pipeline` — that's the
remaining gap.

## Decision

New `samples/hello_rt/` console sample. Phase 136 ships the
**create + SBT** smoke path only — actual `vkCmdTraceRaysKHR`
dispatch is deferred to a follow-up phase because it requires
`DescriptorType::kAccelerationStructure` (currently absent) so the
raygen shader can bind a TLAS via a descriptor set.

Flow:

1. Boot Vulkan device. Bail gracefully (exit 0, no failure) when
   the adapter lacks `ray_tracing` — matches the marathon-honest
   "feature-probe sample" pattern.
2. Compile three minimal RT shaders via `cd::shader::ICompiler`:
   - `raygen` — intentionally empty (no `traceRayEXT`, no
     descriptor access). Validates pipeline create with raygen
     entry.
   - `miss` — writes a constant to the `rayPayloadInEXT`.
   - `closesthit` — writes barycentrics to the payload.
3. Hand the resulting SPIR-V to `device.create_shader_module()`
   for each stage.
4. Create an empty `PipelineLayoutDesc` and pipeline layout
   (no descriptor sets — none of the shaders touch any).
5. Build `RtPipelineDesc` with three `RtShaderEntry` rows (each
   tagged with a unique group index 0/1/2) and call
   `device.create_rt_pipeline(...)`. Failure exits 5.
6. Read `device.rt_shader_group_handle_size/alignment/base_alignment`
   and print them.
7. Allocate a `std::vector<std::byte>` sized at
   `3 * handle_size`, call
   `device.get_rt_shader_group_handles(pipeline, 0, 3, span)`.
8. Sanity-print the first 8 bytes of each group handle to stdout —
   non-zero output confirms the driver produced real unique
   handles.
9. Destroy in reverse order: RT pipeline → pipeline layout →
   three shader modules.

The sample is `cd::sample_common`-free (no window, no
SampleRuntime), exit code is the smoke-test signal.

`cd::shader::ShaderStage` was extended with `kRaygen / kMiss /
kClosestHit / kAnyHit / kIntersection / kCallable` + the glslang
`to_eshlang` switch to land RT shader compilation. Without this
the sample's compile step would default to `EShLangVertex` and
emit garbage SPIR-V.

## Rejected alternatives

- **Full ray dispatch sample with TLAS + storage image.**
  Requires `DescriptorType::kAccelerationStructure` (new variant
  in `Pipeline.hpp` + branches in `update_descriptor_set` for
  Vulkan and D3D12) AND a storage-image binding pattern. Both
  are bounded but together would push this phase past atomic
  scope. Captured as the Phase 137 candidate.
- **Window + swapchain blit of the RT output.** Same blocker —
  no actual dispatch to source the image bytes.
- **Compile the RT shaders ahead of time + ship as SPIR-V
  blobs.** Adds binary assets to the repo + a separate compile
  step in CI. Inline GLSL + glslang at sample boot keeps the
  sample self-contained.

## Consequences

- Sample count: 50 → 51.
- The full chain from Phase 132 (AS build) through Phase 135 (RT
  dispatch) is now driven end-to-end at runtime on any Vulkan
  device with `VK_KHR_ray_tracing_pipeline`. Non-RT adapters
  see a graceful "nothing to do" and exit 0.
- `cd::shader::ShaderStage` enum grew by 6 values; the existing
  `to_eshlang` switch was extended with no behavioural change to
  graphics / compute paths.
- Outstanding: `DescriptorType::kAccelerationStructure` + actual
  `vkCmdTraceRaysKHR` dispatch demo. Tracked for Phase 137.

## Validation

```
cmake --build --preset llvm-win-debug --target cd_sample_hello_rt
./build/llvm-win-base/bin/Debug/hello_rt.exe
```

Builds clean (10/10 targets). Runtime confirmation requires a
Vulkan ICD with RT extensions installed on the host.
