## Bağlam

## Karar

### 42.A — `cd/anim/CurveTrack.hpp`
Sıralı `(t, value)` keyframe + `sample(t)` lineer interpolation.
Endpoint clamp (`<= first` veya `>= last` → ilgili köşe), inside
binary search (lower_bound) + linear blend.

Fade-in/fade-out, audio volume envelope, material parameter sweep
gibi 1-D animasyon track'leri için. Quaternion için Catmull-Rom
(CameraPath), transform için BlendTree2/AdditiveBlend mevcut — bu,
scalar/timeline ailesinin ilk üyesi.

### 42.B — `cd/core/StringSplit.hpp`
`split(view, delim, fn)` — her parça için callback (boş dahil).
`split_nonempty(view, delim, fn)` — boşları atlar.
`count_parts(view, delim)` — O(n) ön-sayım.

Zero-allocation: tüm parçalar `std::string_view` slice. CSV parser,
command palette args, asset URI path walking için yeterli; karmaşık
quoting/escape gerekirse ayrı parser yazılır.
