## Bağlam

Phase 66, marathon'un 69. minor release'i. Audio one-pole low-pass +
asset path variable substitution.

## Karar

### 66.A — `cd/audio/LowPass.hpp`
Classic EMA filter: `y[n] = a*x[n] + (1-a)*y[n-1]`, `a = dt/(RC+dt)`,
`RC = 1/(2π fc)`. SmoothingFilter (Phase 24) time-constant API'sinin
DSP muadili — cutoff frequency + sample rate ile parametrize.

`prepare(rate, cutoff)` / `process(x)` / `reset()` / `alpha()`.

### 66.B — `cd/asset/PathResolver.hpp`
String template variable substitution:
- `set(name, value)` / `clear` / `variable_count`.
- `expand("{LEVEL}/textures/{REGION}.cdtex")` →
  `"level01/textures/tundra.cdtex"`.
- Unknown variable: literally bırakılır (`{UNKNOWN}` ile).
- Unclosed brace: kalanı kopyalanır (defensive).

Scene file template strings, runtime asset path build patterns için.
