# ADR-20260524 / Wave 296 / v0.99.61 / Phase 135 — Vulkan RT pipeline + dispatch_rays

## Status
Accepted — 2026-05-24

## Context

Phase 134 (this run) shipped the cross-backend interface for RT
pipelines + SBT-authoring helpers. This phase lands the Vulkan
backend implementation.

`RtShaderEntry` was refactored mid-phase: from holding GLSL source
to holding a pre-compiled `ShaderModuleHandle`. Reason: the Vulkan
backend doesn't depend on `cd::shader`, and the graphics + compute
pipelines already follow the "caller pre-compiles SPIR-V via
`cd::shader::ICompiler` and passes a module handle" pattern. RT
pipelines now match.

## Decision

### `VulkanDevice::create_rt_pipeline`

- Gates on `features_.ray_tracing` + non-null
  `vkCreateRayTracingPipelinesKHR`.
- Builds `VkPipelineShaderStageCreateInfo` array from
  `RtShaderEntry::module` (looks up `VkShaderModule` from the
  device's `shaders_` map) + `stage` (mapped to
  `VkShaderStageFlagBits` via a switch).
- Pins entry-point names into a `std::vector<std::string>` so the
  `pName` c_str pointers outlive the create call.
- Builds `VkRayTracingShaderGroupCreateInfoKHR` array — one per
  unique `RtShaderEntry::group` index. Each group either:
  - Bundles one general shader (raygen / miss / callable) →
    `VK_RAY_TRACING_SHADER_GROUP_TYPE_GENERAL_KHR`.
  - Bundles closest-hit + optional any-hit + intersection →
    `TRIANGLES_HIT_GROUP_KHR` or `PROCEDURAL_HIT_GROUP_KHR` based
    on whether an intersection shader is present.
- Calls `vkCreateRayTracingPipelinesKHR` with `maxPipelineRayRecursionDepth
  = desc.max_recursion`.
- Stores result in `rt_pipelines_` map keyed by `next_id_`.

### SBT-authoring helpers

Probes `VkPhysicalDeviceRayTracingPipelinePropertiesKHR` at device
init (via `vkGetPhysicalDeviceProperties2`) and caches:
- `rt_shader_group_handle_size()` → `shaderGroupHandleSize`
  (typically 32 B).
- `rt_shader_group_handle_alignment()` → `shaderGroupHandleAlignment`
  (typically 32 B).
- `rt_shader_group_base_alignment()` → `shaderGroupBaseAlignment`
  (typically 64 B).
- `get_rt_shader_group_handles(pipeline, first, count, out)` →
  `vkGetRayTracingShaderGroupHandlesKHR`. Validates output span
  size before the call.

### `VulkanCommandBuffer`

- `bind_rt_pipeline(handle)` — looks up the VkPipeline via a
  static `rt_pipeline_lookup_static_` callback (function-pointer
  through `ResourceTables`, same pattern as Phase 132's
  `accel_lookup`), then calls `vkCmdBindPipeline(VK_PIPELINE_BIND_
  POINT_RAY_TRACING_KHR, ...)`.
- `dispatch_rays(DispatchRaysDesc)` — resolves the four
  `SbtRegion` buffer handles into
  `VkStridedDeviceAddressRegionKHR` (buffer-device-address +
  offset + stride + size), then calls `vkCmdTraceRaysKHR`.

### `ICommandBuffer` interface gain

Added `virtual void bind_rt_pipeline(RtPipelineHandle)` as a
non-pure-virtual no-op so non-RT backends compile unchanged.
Companion to the existing `dispatch_rays` default.

## Rejected alternatives

- **Compile GLSL inside `create_rt_pipeline`.** Would add a
  `cd::shader` dependency to `cd::rhi_vulkan`. Caller-side
  compilation matches the existing graphics + compute pattern.
- **One-`RtPipelineRecord`-per-handle storing the layout too.**
  Caller already manages the `PipelineLayoutHandle` separately;
  duplicating risks divergence.
- **Allocate SBT inside `create_rt_pipeline`.** SBT alignment
  varies by use case (size + record-padding) and crosses the
  cmd-buffer/device boundary awkwardly. Caller authors the SBT
  buffer; the device just provides the handle bytes.

## Consequences

- Vulkan now has end-to-end RT support at the RHI level:
  - Phase 17.A — BLAS create.
  - Phase 127 — TLAS create.
  - Phase 132+133 — BLAS + TLAS cmd-buffer build.
  - Phase 134 — RT pipeline + SBT interface.
  - Phase 135 — RT pipeline impl + bind + dispatch.
- Phase 136 (`hello_rt` real ray dispatch) can now exercise the
  full chain.
- `RtShaderEntry` ABI break — but only one consumer
  (`hello_rt_check` which prints sizeof) and that was caught at
  the same commit.
- Vulkan `kNotImplemented` count: drops to ≤ 1 (just the
  Metal-only entry points hidden behind `#if APPLE`).
