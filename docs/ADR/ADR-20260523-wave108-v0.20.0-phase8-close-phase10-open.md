# ADR — v0.20.0 / Wave 108 — Phase 8 close (7/7) + Phase 10 open (v1.0 path)

- Date: 2026-05-23
- Status: Accepted
- Wave: 108
- Tag: v0.20.0

## Context

v0.19.0 shipped Forward+ GPU compute parity (cluster_assign.comp running on
NVIDIA RTX 3080 Laptop, bit-equal with CPU reference on 3456 clusters /
1033 light assignments). That closed Phase 9 Sprint 2 and left Phase 8's
last routing item — "PBR fragment shader integration" — as a design-debt
hook between the existing cluster grid and the bindless light arrays the
shaders had to read.

After Wave 104 the open trail was:

1. Phase 8 routing item #1: GLSL helper exposing
   `cluster_lookup_id(view_pos)`, `cluster_lookup_light_range(cid)`, and
   `cluster_lookup_light_count()` so PBR fragment code can iterate just
   the local light list per cluster.
2. Phase 10 architectural ADR: switch from "feature breadth" to "v1.0
   path" — feature freeze, quality leg, docs leg, CI/platform leg,
   release leg.
3. cd::diag assertion layer: stable structured `PanicInfo`,
   override hook for unit tests and telemetry, debug-only `CD_ASSERT`,
   release-active `CD_VERIFY`, unconditional `CD_PANIC`.

## Decision

Tag **v0.20.0**, closing Phase 8 at 7/7 routed items and opening Phase 10
as the v1.0 path. Three commits roll up under this tag:

- Wave 105 `feat(cluster_pbr)`: `cd::cluster_pbr::cluster_lookup_glsl()`
  returns a `std::string_view` GLSL helper plus typed
  `DescriptorBindings` and a 32-byte `LookupPushConstants` block.
  Validated by a real glslang compile inside a fragment shader.
- Wave 106 `docs(adr)`: Phase 10 sprint panel — Quality / Docs / CI /
  Release legs and their stop conditions.
- Wave 107 `feat(diag)`: `CD_ASSERT` / `CD_VERIFY` / `CD_VERIFY_MSG` /
  `CD_PANIC` over a process-wide installable `PanicHandler`. Default
  prints structured stderr and aborts; tests swap in a throwing handler.
  `panic()` is intentionally NOT `noexcept` so a throwing handler can
  propagate — otherwise std::terminate would fire on the first test.

## Rejected alternatives

- *Skip Phase 8 item #1 and ship the GPU port alone.* Rejected: the GPU
  side computes the cluster → light range, but fragment-side consumers
  would each invent their own GLSL layout for the storage buffers,
  guaranteeing drift.
- *Build assertions on `<cassert>` + a custom abort wrapper.* Rejected:
  no structured info (typed PanicInfo > printf), no per-process override
  hook (tests need "convert panic to exception"), no path for telemetry
  sinks in production.
- *Open Phase 10 as another breadth sprint.* Rejected: Phase 8 + 9 spent
  100 waves on feature breadth; the next bottleneck before a v1.0 tag is
  not "more features" but stability, API survey, docs, CI surface.

## Consequences

- Phase 8 closes at 7/7 (cluster grid CPU → GPU compute → PBR shader
  integration). No carry-over.
- Phase 10 Sprint 1 (Quality) opens with one item shipped (assertion
  layer) and queues: API stability survey, -Werror tightening, header
  hygiene pass.
- v0.20.0 → v1.0.0 path is the named target. Sprint stop-conditions are
  in Wave 106's ADR; per-sprint ADRs will follow.
- All 58 ctest targets remain green on ninja-debug after the assertion
  layer landed; no behavioral regression in any prior subsystem.
