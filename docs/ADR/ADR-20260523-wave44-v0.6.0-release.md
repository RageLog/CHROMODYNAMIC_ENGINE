# ADR-20260523 — Wave 44: v0.6.0 release tag (Phase 6 night sprint)

## Bağlam

Kullanıcı "sabaha kadar acik birakcsam sabaha kadar bitmeyecek bir plan
yap ve ona devam et" dedi. Bir gecelik sprint Phase 6'nın temel
altyapısını v0.5.0 üzerine inşa etti — networking (real UDP +
retransmit), plugin hot-reload tetikleyici (file watcher), perceptual
image diff, benchmark çıktısı (Markdown), ECS query stale-detection ve
üç showcase sample.

v0.5.0 Phase 5 closure'ı (ADR-20260522-wave36) sonrası bu tag Phase 6
**mid-closure** — Phase 6 routing ADR'sinde listelenen kümelerin BİR
KISMI tamamlandı; geri kalan (Forward+/clustered, mobile RHI, scripting,
real CoreAudio/ALSA implementasyonları, SRTT/RTTVAR estimation, RDCW
inotify/FSEvents) sonraki sprint'lere kalıyor.

## Karar

`v0.6.0` git tag'i atılır. Marathon devam ettiği için "sınıf 0 release"
değil — günlük commit/push hattının bir snapshot'ı. 4/4 Windows
compiler × 54/54 ctest green, yeni samples (hello_udp, hello_watch,
hello_bench Markdown) runtime-clean.

Tag dev branch HEAD'ine atılır; master'a merge kullanıcı izniyle
ayrı PR olarak. v0.4.0 ve v0.5.0 modelinin devamı.

## Reddedilen alternatifler

- **Phase 6 routing ADR kümelerinin tamamını gece içinde bitirmek:**
  Forward+/clustered, mobile RHI, scripting tier — her biri kendi
  mimari ADR'sini hak ediyor; gecede yapılırsa hem token bütçesi
  taşar hem de kararlar acele olur. Bu sprint **temel altyapı**'ya
  odaklandı.
- **v0.5.1 patch tag:** Patch SemVer "bug fix only" iddiası taşır.
  Phase 6 wave'leri yeni feature → minor bump (v0.6.0).
- **Yeni cd::bench library:** Wave 40 başlangıçta yeni bir
  engine/bench/ kütüphanesi kuracaktı. CMake configure error'u
  ortaya çıkardı ki cd::bench zaten engine/foundation/bench/'de var.
  Çakışma yerine mevcut Report sınıfını genişletmek seçildi —
  duplication yok, downstream tüm cd::bench kullanıcıları otomatik
  fayda alıyor.
