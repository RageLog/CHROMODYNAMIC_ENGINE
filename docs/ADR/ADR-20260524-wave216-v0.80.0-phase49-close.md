## Karar

### 49.A — `cd/ui/Tooltip.hpp`
Hover-delay tooltip:
- `set_delay(seconds)` (default 0.5s — VS Code muadili).
- `update(target_id, time_now)` — aynı target için `delay` geçince
  visible=true; target değişirse timer reset; target=0 ise hemen
  clear.
- `visible()` / `target()` query.
- `reset()`.

Caller monotonic saat verir (StableTime / frame loop). Target hash
çağrıya açık (widget pointer, CommandPalette entry id, vb.).

### 49.B — `cd/math/Noise.hpp`
Value noise (lattice-interpolated, hash-driven). API:
- `noise1d/2d(x[, y], seed)` → [0,1].
- `fbm2d(x, y, seed, octaves, lacunarity, persistence)` — fractal
  brownian motion toplam (default 4 octave, lac 2, per 0.5).

`detail::mix32` (PCG-style avalanche) + `hash_lattice(ix,iy,iz,seed)`
hash sample, smoothstep interpolation. Perlin/simplex'ten ucuz; terrain
heightmap preview, particle randomness, procedural texture stub
kullanımı için.
