# ADR-20260524 / Wave 289 / v0.99.54 / Phase 127 — Vulkan TLAS create

## Status
Accepted — 2026-05-24 (TLAS create only; build deferred)

## Context

Phase 17.A landed `create_acceleration_structure(BLAS)` via
`vkCreateAccelerationStructureKHR` + VMA-backed storage buffer.
TLAS stayed stubbed with "lands in 17.B". Phase 117 (this run)
already extended the RHI descriptor to carry an `instances` span;
the matching Vulkan create path was the natural follow-up.

The actual build (`vkCmdBuildAccelerationStructuresKHR`) requires
a command buffer + instance buffer upload + scratch buffer + a
`VkCommandBuffer` to record into. The engine's
`ICommandBuffer::build_acceleration_structure` is still a default
no-op virtual, so this phase ships **create-only**. Build comes
in the follow-up RT pipeline phase.

## Decision

Mirror the BLAS create path with three TLAS-specific tweaks:

1. **Geometry type** = `VK_GEOMETRY_TYPE_INSTANCES_KHR`. The
   `geometry.instances` field is filled with `arrayOfPointers =
   VK_FALSE` and a **placeholder device address of 0** — Vulkan
   spec allows this in the size query because sizes only depend
   on instance count, not on the instance buffer contents.
2. **Primitive count** = number of instances in the desc
   (`desc.instances.size()`).
3. **AS type** = `VK_ACCELERATION_STRUCTURE_TYPE_TOP_LEVEL_KHR`.

The result is a TLAS object backed by a properly-sized device-
local buffer, ready for `vkCmdBuildAccelerationStructuresKHR` once
the command-buffer build path is wired (Phase 128 candidate).
`destroy_acceleration_structure` already handles both kinds (no
change needed).

## Rejected alternatives

- **Real build inline (inside `create_*`).** Requires acquiring a
  transient command buffer, uploading the instance data, allocating
  scratch — fits a "RT pipeline" phase (Phase 128) better. The
  separation between create-AS-object and build-AS-data matches
  Vulkan's own API split.
- **Lazy size query via worst-case 1 MB allocation.** Wastes VRAM
  and may not satisfy the Vulkan-spec lower bound for the build.
  The placeholder device-address trick is the documented pattern.

## Consequences

- Vulkan AS path: BLAS create + TLAS create both real. Build path
  for both is still a no-op virtual.
- Phase 117's interface contract is now backed by a working create
  on Vulkan.
- Vulkan backend `kNotImplemented` count unchanged at 3 (the
  remaining stubs are RT pipeline + AS build path placeholders;
  TLAS create was the BLAS path's `if (kind != Bottom)` short-
  circuit rather than a numbered stub).

