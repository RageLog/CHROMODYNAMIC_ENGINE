# ADR-20260524 / Wave 282 / v0.99.47 / Phase 118 — RT Pipeline + SBT interface

## Status
Accepted — 2026-05-24

## Context

`AccelStructureDesc` (Phase 117) handles BLAS + TLAS data. The
ray-tracing pipeline itself — shader stages, recursion depth,
payload sizes — plus the shader binding table that
`vkCmdTraceRaysKHR` consumes were still missing from the RHI
surface.

## Decision

Three new descriptor types in `cd::rhi`:

1. **`RtShaderStage` enum** — `kRaygen / kMiss / kClosestHit /
   kAnyHit / kIntersection / kCallable`. Mirrors
   `VkRayTracingShaderGroupTypeKHR` + DXR hit-group categories.

2. **`RtShaderEntry`** — `(stage, glsl source, entry name, group
   index)`. Same-group entries are tied into one hit group
   (closest-hit + any-hit + intersection).

3. **`RtPipelineDesc`** — `(shaders, max_recursion,
   max_payload_bytes, max_attribute_bytes, debug_name)`. Defaults
   tuned to "1 bounce, 64 B payload, 32 B attrs" which fits most
   single-bounce ray-cast samples.

4. **`SbtRegion`** — `(buffer, offset, stride_bytes, size_bytes)`.
   Mirrors `VkStridedDeviceAddressRegionKHR`.

5. **`DispatchRaysDesc` extended** — gains four `SbtRegion`
   members (raygen / miss / hit / callable). Raygen is required;
   the others are optional (skip if buffer invalid).

Vulkan implementation lands in a follow-up phase
(`vkCreateRayTracingPipelinesKHR`, SBT alignment, AS-aware
descriptors). This commit is the RHI interface only.

## Rejected alternatives

- **One `RtShaderGroup` struct (closesthit + anyhit +
  intersection bundled).** Tempting because Vulkan groups them,
  but the flat list with `group` index is closer to how DXR
  builds hit groups via the same shader handles. Easier to
  describe arbitrary mixes.
- **Pre-compile SPIR-V slot in the descriptor.** Two-way
  initialization is messy; the cd::shader compile path already
  exists and `RtPipelineDesc` just hands raw GLSL through it.
- **Inline payload struct in the descriptor.** Engine-side
  payload layout drift between RT shaders and consumer code is a
  separate problem. Recording the budget (`max_payload_bytes`)
  is enough at the RHI tier.

## Consequences

- `cd::rhi::IDevice` gains a `create_rt_pipeline(RtPipelineDesc)`
  shape (default impl will return `kNotImplemented` until Phase
  119 wires Vulkan).
- Samples / tools that want to author RT shaders now have a
  single struct describing the pipeline shape; previously every
  consumer would have had to invent its own.
- No backend code changes; full build remains green.
