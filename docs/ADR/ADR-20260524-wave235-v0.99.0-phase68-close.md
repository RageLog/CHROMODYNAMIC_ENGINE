## Karar

### 68.A — `cd/math/QuatLog.hpp`
- `quat_log(q)` — pure imaginary log(q) = (0, θ·n).
- `quat_exp(v)` — unit quaternion exp(v).
- `quat_pow(q, t)` — fractional rotation, `t=0` identity, `t=1` q.

Small-angle (`|v| < 1e-6`) clamp → identity fallback yapı.
AdditiveBlend (Phase 31) ile birlikte weighted-additive layer için
canonical scale operation.

### 68.B — `cd/ui/Toast.hpp`
- `Toast { id, message, severity, expiry_t }`.
- `ToastSeverity { Info, Warn, Error }`.
- `ToastQueue.push(msg, dur, now, sev)` — auto-ID.
- `update(now)` — expired toast evict.
- `dismiss(id)` — manual close.
- `active()` view.

Editor user-facing transient notification ("Scene saved", "Compile
failed: …", "Texture imported") için backing state. Renderer-agnostic.

**v1.0 yaklaşıyor** — son birkaç wave consolidation içeriyor.
