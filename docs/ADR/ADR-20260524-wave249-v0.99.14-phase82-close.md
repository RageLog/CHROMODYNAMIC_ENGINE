## Karar

### 82.A — `cd/audio/PanLaw.hpp`
- `linear_pan(p)` — `L=(1-p)/2`, `R=(1+p)/2`. Center attenuated by
  3dB compared to endpoints.
- `constant_power_pan(p)` — `L=cos(angle)`, `R=sin(angle)`, energy=1.
  Industry default for music.
- `p ∈ [-1, 1]` clamped.

3D positional audio post-process katmanı için stereo bus pan
hesabı.

### 82.B — `cd/math/Damping.hpp`
- `critical_damping(k)` — kritik damping coef.
- `step_critically_damped(current, velocity, target, stiffness, dt)`
  — single scalar.
- `step_critically_damped_vec3(...)` — array form.

Smooth follow camera, UI animation, hot-reload value transitions
için Game Programming Gems formülü. Stable explicit Euler — `dt * k
< 1` korumalı.
