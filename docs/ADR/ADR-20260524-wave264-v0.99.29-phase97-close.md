## Karar

### 97.A — `cd/core/Assert.hpp`
- `CD_ASSERT(cond)` — debug-only invariant (NDEBUG = no-op).
- `CD_VERIFY(cond)` — always-on, even release.
- Custom `set_assert_handler(fn)` allows engine to hook crash report /
  dev "ignore + continue" UI.
- Default: print to stderr + `std::abort()`.

CLAUDE.md §1 modern C++ kalitesi (bellek + sınır kontrolü) için
sözleşme.

### 97.B — `cd/scene/SceneStats.hpp`
Aggregate scene summary struct:
- `entity_count`, `mesh_renderer_count`, `light_count`.
- `total_triangle_count` (u64 — büyük sahneler için).
- `estimated_bytes` (mesh + texture + anim toplamı).
- `bbox_min/max` + `bbox_extent(s)` helper.

Editor "Scene Info" inspector + ProfilerView memory bar için
backing data.
