  caller ImGui tree node ile render eder.

- Walk `scene.children_of(e)` ile depth-first; collapsed children
  görünmez.

Editor sahne hierarchy panel'inin headless state'i. Rendering
ImGui'ye delegate, primitive sadece tutum.

### 78.B — `cd/math/Smoothstep.hpp`
`smoothstep` zaten `Easing.hpp`'de var; bu header ek olarak:
- `smootherstep(t)` — Perlin C² (6t⁵-15t⁴+10t³).
- `smoothstep_remap(edge0, edge1, x)` — GLSL-style range remap.

Edge case: `edge1 <= edge0` → 0 (degenerate).

### Test fix

definition compile hatası verdi. Smoothstep.hpp şimdi Easing.hpp'i
include eder ve sadece ek helper'lar koyar. Tests yalnız yeni
smootherstep + smoothstep_remap'ı doğruluyor.
