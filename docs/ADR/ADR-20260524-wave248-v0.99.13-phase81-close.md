### 81.B — `cd/asset/DependencyGraph.hpp`
Reverse edge map (`child → set<parent>`):
- `depend(parent, child)` — edge ekle.
- `dependents_of(child)` — 1-hop reverse lookup.
- `transitive_dependents(child)` — BFS closure.
- `edge_node_count` / `clear`.

Hot-reload: texture changed → material reloads → scene refreshes
chain'i bu graph üzerinden walk.
