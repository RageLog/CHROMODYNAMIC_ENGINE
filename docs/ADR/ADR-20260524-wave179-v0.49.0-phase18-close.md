### 18.B — OpenGL backend boot (cd::rhi_opengl)
**Headline of Phase 18** — the 3rd API priority joins the engine.

- New library `engine/render/rhi_opengl/`. Header
  `cd/rhi_opengl/OpenGLDevice.hpp` exposes `GLCreateInfo` +
  `create_gl_device()`.
- Win32 path: dummy hidden window + ChoosePixelFormat +
  SetPixelFormat + wglCreateContext + wglMakeCurrent. Reads
  `glGetString(GL_RENDERER)` for adapter name + `glGetString(
  GL_VERSION)` for version probe.
- Non-Windows path: stub returning kBackendInitFailed (Linux
  GLX / EGL + macOS NSOpenGLContext follow in a later wave).
- Boot-only — all resource entry points return kNotImplemented
  with a clearly-worded message (mirrors the D3D12 v0.27.0
  → v0.36.0 progression).
- New sample `hello_opengl_boot` verified on the marathon
  machine's Intel Iris Xe Graphics:
  ```
  CHROMODYNAMIC 0.49.0 — hello_opengl_boot
  [gl] backend=4  adapter=Intel(R) Iris(R) Xe Graphics
  [gl] boot OK
  ```

### 18.E — cd::net::PredictionBuffer (client-side prediction)
Header-only ring buffer of (sequence, state) snapshots.
- `record(seq, state)` adds a snapshot; eviction is oldest-first
  when full.
- `at(seq)` returns the state by sequence number.
- `correct_and_replay(seq, server_state, apply)` performs the
  server-correction roll-back: replaces the snapshot at `seq`
  with the authoritative state, then re-applies `apply(prev, seq)`
  to every later snapshot. Returns the count replayed.
- Three unit tests pin the contract:
  - RecordAndLookup
  - EvictsOldestWhenFull
  - CorrectAndReplayRebuildsState

### 18.A / 18.C / 18.D / 18.F — deferred to Phase 19

Honest scope: Phase 18 ships two solid items (the OpenGL boot

The marathon's "ship coherent chunks; don't half-land" discipline
applies — better to land 2 complete sub-phases than 6 half-done.
