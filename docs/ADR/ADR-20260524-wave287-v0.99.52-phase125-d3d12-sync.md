# ADR-20260524 / Wave 287 / v0.99.52 / Phase 125 — D3D12 sync primitives

## Status
Accepted — 2026-05-24

## Context

D3D12_PARITY_AUDIT.md (Phase 122) listed D3D12 fence / semaphore /
timeline-semaphore as priority #2 — five `kNotImplemented` stubs
plus two no-op overrides. Until they land, the D3D12 backend can't
frame-pace, doesn't gate ImGui upload completion, and can't drive
async-compute timelines.

## Decision

Implement all five entry points + the two no-op overrides as a
single contiguous block. D3D12 has only one queue-side sync
primitive (`ID3D12Fence`) that already behaves like a Vulkan
timeline semaphore (u64 monotonic counter). All three wrapper
types share an `ID3D12Fence` underneath:

| Engine wrapper        | D3D12 backing       | Host wait                |
|-----------------------|---------------------|--------------------------|
| `SemaphoreHandle`     | `ID3D12Fence` + u64 | (queue-side only)        |
| `FenceHandle`         | `ID3D12Fence` + `HANDLE` event | `SetEventOnCompletion` + `WaitForSingleObject` |
| `TimelineSemaphoreHandle` | `ID3D12Fence` + `HANDLE` event | same as fence |

Behavioural details:

- **`create_fence(signaled)`** — `ID3D12::CreateFence(initial=0 or 1)`,
  Win32 `CreateEventW` for host wait. `target_value` matches the
  initial so `is_fence_signaled` is consistent.
- **`wait_for_fence(handle, timeout_ns)`** — fast-path
  `GetCompletedValue` short-circuit; else `SetEventOnCompletion` +
  `WaitForSingleObject` with ns→ms (round up) conversion.
  `timeout_ns == 0` AND `timeout_ns == UINT64_MAX` both map to
  `INFINITE`, matching Vulkan's "block forever" semantic.
- **`reset_fence`** — bumps `target_value` (D3D12 fences are
  monotonic; caller queues the next `ID3D12CommandQueue::Signal`).
- **`is_fence_signaled`** — `GetCompletedValue >= target_value`.
- **`create_timeline_semaphore(initial_value)`** — direct fence
  creation at that initial value. `signal_timeline_semaphore`
  calls `ID3D12Fence::Signal` host-side (queue-side signal needs
  the command queue and is handled elsewhere).
- **`destroy_*`** — `CloseHandle` the event, drop the registry
  entry.

New private structs `SemaphoreRecord`, `FenceRecord`,
`TimelineRecord` + three `unordered_map` registries on the device.

## Rejected alternatives

- **Backed by `D3D12_FENCE_FLAG_SHARED`.** Cross-process sharing
  is out of scope. Plain fences are simpler.
- **Use a single registry keyed by abstract "fence-like" handle.**
  Loses the type discrimination the engine surface promised.
  Three small maps cost ~144 B each plus an entry per primitive —
  negligible.
- **Implement `acquire_next_image` / `present` to actually consume
  the semaphore.** DXGI flip-model handles its own backbuffer
  fencing. Documented in source.

## Consequences

- D3D12 `kNotImplemented` site count drops from 8 → 4 (semaphore,
  fence, timeline-semaphore × 3 wait/signal/destroy paths handled).
- ImGui DX12 backend + Renderer frame pacing now have a working
  D3D12 fence to drive against.
- `rhi_errors::Code::kTimeout` is now produced by D3D12; verify
  no Vulkan code path treats this as fatal.

## Validation

```
cmake --build --preset llvm-win-debug --target cd_rhi_d3d12
```

D3D12 backend builds clean.
