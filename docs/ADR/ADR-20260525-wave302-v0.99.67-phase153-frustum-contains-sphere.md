# ADR Wave-302 — Phase 153 Frustum::test_sphere / contains_sphere (v0.99.67)

- **Date:** 2026-05-25
- **Status:** Accepted
- **Predecessor:** [ADR-20260525-wave301-v0.99.66-phase149-renderer-submit-draws](./ADR-20260525-wave301-v0.99.66-phase149-renderer-submit-draws.md)
- **Successor:** ADR Wave-303 (Phase 154 hello_engine save/load round-trip)
- **Tag:** v0.99.67

## Context

`cd::camera::Frustum` exposed only `test_aabb` for view-frustum culling.
Many engine primitives are naturally bounded by spheres (point lights,
particle systems, mesh bounding spheres), and the sphere test is cheaper
than the AABB p/n-vertex test — one dot per plane vs. eight-corner
selection.

`hello_engine`'s PBR sphere sweep was driving its cull-counter from a
trivial `z < -10.0F` stub. The MARATHON_SUMMARY "Outstanding integration"
list explicitly called out:

> Frustum::contains_sphere

This phase closes that gap.

## Decision

Two new header-only inlines in `cd/camera/Frustum.hpp`:

```cpp
[[nodiscard]] CullResult test_sphere(
    const Frustum&, const cd::math::Vec3f& center, float radius) noexcept;

[[nodiscard]] bool contains_sphere(
    const Frustum&, const cd::math::Vec3f& center, float radius) noexcept;
```

`test_sphere` returns the same three-valued `CullResult` as `test_aabb`
so it composes the same way into hierarchical culling. Per-plane logic:

- `d < -radius` → entire sphere outside that plane → `kOutside` immediately
- `|d| <= radius` on any plane while no plane rejects → `kIntersecting`
- `d > radius` on every plane → `kInside`

`contains_sphere` is a one-line convenience: true iff `test_sphere`
returns anything other than `kOutside` — matches the naming users will
reach for in cull-stats panels.

Five new tests in `cd_test_camera` pin the contract:

- `SphereAtOriginIsVisible`
- `SphereBehindCameraIsCulled`
- `SphereOffToTheSideIsCulled`
- `LargeSphereStraddlingFrustumReportsIntersecting`
- `TinyCentralSphereReportsKInside`

All pass.

## hello_engine integration

`hello_engine` now extracts a `Frustum` from the per-frame VP and
classifies the 5×5 PBR sphere sweep via `test_sphere`. New counters:

- `culled_pbr`        — fully outside
- `intersecting_pbr`  — straddles frustum
- `inside_pbr`        — fully inside

These are now driven by **real** frustum math, not a Z stub.

## Rejected alternatives

- **`bool only`** signature (drop `CullResult`) — would have been
  cheaper to implement but loses the kIntersecting/kInside fast path
  that hierarchical culling depends on.
- **Take the sphere as `Vec4f { x, y, z, r }`** — slightly more compact
  but breaks the convention `test_aabb(min, max)` set: every cull
  primitive in `cd::camera` now takes naked geometry args.

## Consequences

- One more "outstanding integration" bullet closed.
- Engine now ships **both** the AABB and sphere cull tests with parity
  semantics (`CullResult` everywhere) — hierarchical cull bridges
  (octree → leaf) can mix the two without translating result types.

## Open follow-ups

- A `test_obb` (oriented bounding box) would round out the cull-primitive
  set; left for a future phase as no current engine consumer needs it.
- The PBR sweep's cull radius of 0.5 is a hand-tuned constant; once
  mesh-asset bounding-sphere extraction lands, hello_engine should
  pull the value from the asset instead.
