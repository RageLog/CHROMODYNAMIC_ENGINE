## Bağlam

Phase 61, marathon'un 64. minor release'i. Rhi vertex-layout builder +
io path-string helpers.

## Karar

### 61.A — `cd/rhi/VertexLayoutBuilder.hpp`
Fluent builder:
- `bytes_of(Format)` — Format → byte boyutu (R32F=4, RGB32F=12,
  RGBA8Unorm=4, vb.).
- `VertexLayoutBuilder.add(Format, [binding=0])` — `location` ve
  `offset` auto-increment.
- `build()` → `vector<VertexAttribute>`.
- `stride()` — toplam vertex byte boyutu.

PSO build sites artık tek bir builder ile vertex layout kuruyor;
manual location/offset hesabı kaldırıldı.

### 61.B — `cd/io/PathUtils.hpp`
String_view path slice'ları (zero-alloc):
- `filename(path)` — son `/` sonrası.
- `extension(path)` — son `.` sonrası (filename'in pos 0'daki dot
  hariç → ".hidden" exception olarak ele alınmaz).
- `stem(path)` — filename without extension.
- `parent(path)` — son `/` öncesi.

Asset loader, scene importer, hot reload path manipulation için
ortak slice helper'ları.

- **VertexLayout için struct introspection (offsetof, sizeof)**:
  reflection benzeri runtime helper'lar var ama explicit builder
  artist tooling açısından daha temiz.
- **PathUtils'i `std::filesystem::path` üzerine kurmak**: filesystem
  std::string allocate eder; ASSET path hot loop'ları için string_view
  slice doğru tercih.
