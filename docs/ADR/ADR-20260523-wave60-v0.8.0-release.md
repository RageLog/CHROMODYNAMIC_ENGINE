# ADR-20260523 — Wave 60: v0.8.0 release tag (Phase 6 Sprint 3)

## Bağlam

Kullanıcı "sabaha kadar acik birakcsam sabaha kadar bitmeyecek bir plan
yap ve ona devam et" dedi. Gecenin üçüncü sprint'i — Sprint 3, Wave 53-59
ile devam etti. Bu ADR + tag Sprint 3'ü resmi olarak kapatır.

Sprint 1 (Wave 37-43, v0.6.0): networking + plugin watcher temel.
Sprint 2 (Wave 45-51, v0.7.0): networking polish (SRTT, cum-ACK), watcher
parity, bench JSON, soak harness.
Sprint 3 (Wave 53-59, v0.8.0): SACK, perceptual diff foundation, JSON
logging, deferred events, frame pacing, changelog tooling, showcase.

## Karar

`v0.8.0` git tag'i atılır. Marathon devam ediyor — tek-kişi gece sprint'in
üçüncü snapshot'ı. 4/4 Windows compiler × 54/54 ctest green.

Tag dev branch HEAD'ine; master merge ayrı PR (v0.4/0.5/0.6/0.7 modelinin
devamı).
