# ADR Wave-306 — Phase 141 hello_rt real ray dispatch (v0.99.71)

- **Date:** 2026-05-25
- **Status:** Accepted
- **Predecessor:** [ADR-20260525-wave305-v0.99.70-phase140-accel-descriptor](./ADR-20260525-wave305-v0.99.70-phase140-accel-descriptor.md)
- **Successor:** ADR Wave-307 (Phase 151 SelectionOutline)
- **Tag:** v0.99.71

## Context

Phase 136 (v0.99.62) shipped `hello_rt` as a smoke test that
**created** an RT pipeline + SBT handles but **never traced a ray**.
Phase 140 (v0.99.70) added the missing
`DescriptorType::kAccelerationStructure` so a TLAS could be bound
into a raygen shader. The remaining work was to wire those pieces
together end-to-end.

## Decision

Rebuild `samples/hello_rt/main.cpp` around a real
`vkCmdTraceRaysKHR` dispatch:

1. **Shaders** — the raygen now binds `accelerationStructureEXT tlas`
   at `(set=0, binding=0)` and `image2D img` at `(set=0, binding=1)`,
   shoots a ray per launch ID, and writes the resulting payload as
   the per-pixel color via `imageStore`. Miss shader returns sky
   color; closest-hit returns the barycentric debug palette.

2. **BLAS + TLAS** — single equilateral triangle BLAS, one identity
   TLAS instance. Built via `cmd.build_acceleration_structure` per
   Phase 132's API.

3. **Storage image output** — 256×256 RGBA8 `kStorage` + `kTransferSrc`
   texture. Transitioned `kUndefined → kUnorderedAccess` before
   dispatch so `imageStore` is legal.

4. **SBT buffer** — three regions (raygen / miss / hit), each
   base-aligned per device-reported alignment, handle-strided per
   `rt_shader_group_handle_alignment`. Allocated via the new
   `BufferUsage::kShaderBindingTable` flag.

5. **Descriptor set** — one set with two bindings: the TLAS via the
   new `kAccelerationStructure` write (Phase 140) and the storage
   image view via `kStorageImage`. Update goes through
   `device.update_descriptor_set` and exercises the
   `VkWriteDescriptorSetAccelerationStructureKHR` pNext chain
   landed in Phase 140.

6. **Command-buffer record** — begin → build BLAS → build TLAS →
   transition image → bind RT pipeline → bind descriptor set →
   `dispatch_rays(256, 256, 1)` → end → submit → wait_idle.

## Side fix

`vmaCreateAllocator` was being passed `flags=0`, but enabling
`bufferDeviceAddress` on the device without
`VMA_ALLOCATOR_CREATE_BUFFER_DEVICE_ADDRESS_BIT` on the allocator
trips a VMA assertion the first time anyone allocates an SBT or AS
scratch buffer. Conditional on `rt_enabled` so the non-RT path keeps
its old behavior.

## Test result

```
[hello_rt] adapter: NVIDIA GeForce RTX 3080 Laptop GPU
[hello_rt] 3 RT shader modules compiled.
[hello_rt] RT pipeline created (3 groups: raygen/miss/hit).
[hello_rt] RT properties:
           handle size       = 32 B
           handle alignment  = 32 B
           base alignment    = 64 B
[hello_rt] descriptor set updated (TLAS @ 0, storage image @ 1).
[hello_rt] dispatch_rays(256 x 256) executed + waited.
[hello_rt] OK — TLAS-bound real ray dispatch verified on this adapter.
```

Validation layers report zero errors. The dispatch + wait_idle path
proves the full RT chain is wired end-to-end.

## Rejected alternatives

- **Readback + PNG output** — would have made the sample visually
  verifiable but pulls in a PNG encoder that isn't in the engine
  yet. The dispatch-with-validation-clean signal is enough to prove
  the chain works; visual readback is a follow-up.
- **Use 2 separate descriptor sets** (one per binding) — single set
  is simpler and matches how production engines build RT descriptor
  sets.
- **Skip the BLAS build inside the command buffer** (do it inline
  during create_acceleration_structure) — the explicit-build API
  matches the rest of the engine's "create returns a handle, then
  record build" pattern; deferring it to the GPU lets multiple AS
  builds batch.

## Consequences

- The full Vulkan RT chain — descriptors, pipelines, AS, SBT,
  dispatch — is now exercised end-to-end by a sample in the tree.
- Marathon's WAVE B (RT completion) is complete.
- `hello_rt`'s leading docstring is now accurate ("real dispatch")
  whereas Phase 136 had to disclaim it.

## Open follow-ups

- Phase 142 — D3D12 DXR Tier 1.1 mirror.
- Image readback + PNG output, once the engine ships a PNG encoder

- A `cd_test_rhi_vulkan_rt` automated test that does the same
