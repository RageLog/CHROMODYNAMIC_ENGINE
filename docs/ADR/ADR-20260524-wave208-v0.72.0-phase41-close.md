# ADR-20260524 wave208 — v0.72.0 Phase 41 close

## Bağlam

Phase 41, audio safety-net (limiter) ve UI design-token (theme palette)
primitive'lerini ekler.

## Karar

### 41.A — `cd/audio/Limiter.hpp`
Feed-forward peak limiter. Envelope follower (attack/release time
constants) `|x|`'i takip eder; `env > threshold` durumunda
`gain = T/env` clamp uygular. Gain bir-pol low-pass ile smooth — soft
knee ile saturation karakteri.

`prepare(rate, threshold=0.95, attack=1ms, release=50ms)` sane default'lar.
Master bus safety-net olarak kullanılır; broadcast LUFS-aware mastering
scope dışı.

### 41.B — `cd/ui/Theme.hpp`
Color32 + Theme struct: background/surface/primary/danger/accent +
on_* foreground'lar + spacing tokens (pad_xs/s/m/l/xl + corner_radius).

`dark_theme()` (#1E1E1E zemin, mavi primary) ve `light_theme()` factory.
Non-ImGui UI yolu (terminal UI, custom HUD, custom Anchor surface)
hep aynı palet üzerinden çizer.
