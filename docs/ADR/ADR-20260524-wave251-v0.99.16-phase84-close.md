### 84.B — `cd/math/QuadraticSolver.hpp`
Numeric-stable `ax² + bx + c = 0`:
- `b` dominantsa catastrophic cancellation'dan kaçınmak için
  `q = -0.5 * (b + sign(b)·√Δ)` formulation, sonra
  `x1 = q/a`, `x2 = c/q` (Vieta).
- Linear edge (`a ≈ 0`) ve negative discriminant doğru handle edilir.
- Roots ascending sıralı döner.

Ray-sphere kesişimi, projectile interception, motion-blur sample
intersection için.
