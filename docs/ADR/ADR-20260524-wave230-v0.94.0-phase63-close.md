## Karar

### 63.A — `cd/ui/Spinner.hpp`
Counterpart to ProgressBar (Phase 57). State = single angle in
radians, advanced by `tick(dt)` at `speed_rps` rotations/sec. Angle
wraps [0, τ).

`kTau = 6.28318...F` constant inline'd (UI sadece cd::core'a depend
ediyor; cd::math include etmek dep DAG'da gereksiz şişme).

### 63.B — `cd/math/Histogram.hpp`
Fixed-bucket frequency counter:
- ctor `(bucket_count, min, max)` — eşit-genişlikli bucket'lar.
- `record(x)` — out-of-range clamp-to-edge.
- `count(i)` / `total()` / `bucket_count()`.
- `mode_bucket()` — busiest bin.
- `clear()`.

ProfilerView frame-time grafiği için Statistics (Phase 56) ile
çift olarak; statistics özet sayılar, histogram dağılım şekli.
