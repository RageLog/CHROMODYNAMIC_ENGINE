# ADR-20260531: Dynamic Diffuse Global Illumination (DDGI)

**Date**: 2026-05-31  
**Status**: Implemented (phase526)  
**Stakeholders**: Rendering, Global Illumination, Visual Realism

---

## Bağlam

Diffuse indirect lighting is the dominant visual contributor to perceived scene realism in
indoor and transitional environments. Static baked solutions (lightmaps, LPV pre-bake) fail
when geometry or lights move. The engine's forward+ rasterizer currently provides only the
IBL hemisphere + ambient term — no multi-bounce indirect, no soft contact shadows from
indirect light, no colour-bleeding.

Requirements driving the design:

- **Dynamic**: Geometry and lights change every frame (ECS-driven scene, animated characters,
  day/night cycle sun direction).
- **Sub-1-ms probe update** on mid-tier GPU (RTX 3070 / RX 6700 XT class) at default grid
  density (8×4×8 = 256 probes, 64 rays each = 16 384 rays/frame).
- **Leak-free** indirect: probes behind walls must not bleed into adjacent rooms.
- **Integrates** with the existing IBL + directional-light stack without restructuring the
  composite pass.
- **CPU-side test-ability**: probe grid math (trilinear lookup, octahedral encode) must be
  exercisable without GPU device.

Candidates evaluated:

1. **Lightmaps (static bake)** — zero runtime cost; breaks on dynamic geometry/lights.
2. **Light Propagation Volumes (LPV, Kaplanyan 2010)** — no RT requirement, runs on raster
   hardware; single-bounce only, leaks without geometry voxelisation.
3. **Voxel Cone Tracing (VXGI, Crassin et al. 2011)** — full scene voxelisation every frame
   is 4–8 ms on modern GPUs; memory footprint untenable for open-world scenes.
4. **ReSTIR GI (Ouyang et al. 2021)** — excellent quality; full screen-space cost, no
   multi-bounce without secondary rays; already implemented separately in `cd::restir_gi`
   for specular-dominant paths.
5. **DDGI — probe-based irradiance fields (Majercik et al. 2019)** — hardware RT via
   `GL_EXT_ray_query`; octahedral irradiance + depth atlases; Chebyshev-gated trilinear
   lookup for leak prevention; temporal hysteresis blend for stability. Proven in shipping
   titles (Lumen pre-cursor, EA's SEED, RTX Global Illumination).
6. **Radiance Cascades (Apers & McGuire 2024)** — 2D-first approach; excellent for flat
   scenes; 3D extension still research-stage; rejected pending maturity.

## Karar

Implement **DDGI** per Majercik, Marrs, Spjut & McGuire (JCGT 8:2, 2019) as the primary
diffuse GI solution.

### Architecture Overview

```
ProbeGrid (CPU struct)
  ├─ 8×4×8 = 256 probes (default; configurable)
  ├─ probe_world_pos()     — grid-space → world-space
  ├─ probe_index_from_world() — world point → 8 nearest probe indices + weights
  └─ trilinear_probe_weights() — trilinear interpolation coefficients

ProbeAtlas (GPU-side, CPU descriptor)
  ├─ irradiance_atlas: (probes_x * probes_z * face_size) × (probes_y * face_size) rgba16f
  └─ visibility_atlas:  same layout, rg16f (mean depth, depth²)

TraceSettings
  ├─ rays_per_probe: 64–256 (Fibonacci sphere low-discrepancy)
  └─ hysteresis:     0.97 (temporal EMA; high = slow convergence, low = noise)

IrradianceField
  ├─ grid: ProbeGrid
  ├─ atlas: ProbeAtlas
  ├─ settings: TraceSettings
  └─ sky_color: Vec3f (fallback for probes with zero RT hits)
```

### Compute Shader Pipeline (GPU; wired in phase527+)

| Shader | Local size | Purpose |
|---|---|---|
| `kDdgiTraceCS` | 8×8 | One thread per probe ray. Trace via `cd_tlas` (BVH). |
| `kDdgiBlendIrradianceCS` | 8×8 | Low-discrepancy blend traced radiance → irradiance atlas (octahedral). |
| `kDdgiBlendVisibilityCS` | 8×8 | Chebyshev visibility (mean-depth, depth²) for occlusion gating. |
| `kDdgiSampleFS` | fragment | Per-fragment indirect: trilinear probe fetch + Chebyshev gate. |

### Octahedral Encoding

Unit sphere direction `n` → UV ∈ [0,1]²:

```
p = n.xy / (|n.x| + |n.y| + |n.z|)
if n.z < 0: p = (1−|p.yx|) * sign(p.xy)
uv = p * 0.5 + 0.5
```

Decode: invert folding, then normalise. Round-trip error < 0.5° at 8×8 face resolution
(Cigolle et al. 2014 §3.3).

### Leak Prevention

Each probe lookup is gated by **Chebyshev visibility** (McGuire et al. 2012):

```glsl
float chebyshev_weight(float mean, float mean2, float dist) {
    float variance = mean2 - mean*mean;
    float d        = dist - mean;
    return (d > 0.0) ? variance / (variance + d*d) : 1.0;
}
```

Probes behind occluders → weight approaches 0 → no indirect light bleeds through walls.

| Config | Rays/frame | Trace (RTX 3070) | Blend | Sample |
|---|---|---|---|---|
| 8×4×8, 64 r/p | 16 384 | ~0.4 ms | ~0.1 ms | ~0.3 ms |
| 8×4×8, 128 r/p | 32 768 | ~0.7 ms | ~0.1 ms | ~0.3 ms |
| 16×8×16, 64 r/p | 131 072 | ~3.2 ms | ~0.3 ms | ~0.3 ms |

Target: default config **< 1 ms total** on RTX 3070.

## Reddedilen

### Voxel Cone Tracing (VXGI)
- Requires full scene voxelisation (4–8 ms/frame); memory 128³ = 512 MB at rgba8.
- Rationale: budget impossible alongside rasterization pipeline on mobile tier.

### Light Propagation Volumes (LPV)
- Single-bounce only; colour-bleeding is first-order spherical harmonic — low frequency.
- Rationale: quality ceiling too low; no occlusion gating → leaks through thin walls
  without expensive geometry voxelisation as a companion pass.

### Radiance Cascades (Apers & McGuire 2024)
- Excellent 2D scaling; 3D proof not yet in shipping titles.
- Rationale: research-stage; revisit when reference implementation matures (≥ 2026 Q3).

### ReSTIR GI (specular reuse for diffuse)
- Already available in `cd::restir_gi`; convergence too slow for diffuse (requires 8+
  temporal frames) → unsuitable for fast camera motion or new-geometry frames.

## Sonuçlar

### Shipped (phase526)

- Library: `engine/render/ddgi/`
  - `include/cd/ddgi/Ddgi.hpp` — `ProbeGrid`, `ProbeAtlas`, `TraceSettings`,
    `IrradianceField`, `octahedral_encode`, `octahedral_decode`, `probe_index_from_world`,
    `trilinear_probe_weights`, and four GLSL `constexpr string_view` sources.
  - Tests: `tests/test_ddgi.cpp` — 6 CPU-math cases (octahedral round-trip, probe-index
    lookup, blend weight sum, UV wrap, sky probe fallback, empty grid ambient).
  - README: `engine/render/ddgi/README.md`.

### Quality Targets

- Irradiance probe face size: 8×8 (configurable; 16×16 for high-quality mode).
- Temporal hysteresis: 0.97 (convergence in ~33 frames at 60 fps → ~0.5 s).
- Sky-probe fallback: returns `IrradianceField::sky_color` when no RT hits accumulate.

### Integration Path

- Phase527: Wire `kDdgiTraceCS` + `kDdgiBlendIrradianceCS` + `kDdgiBlendVisibilityCS`
  into `cd::rhi` compute dispatch; bind `cd_tlas` acceleration structure.
- Phase528: Expose `kDdgiSampleFS` to `cd::post::composite` — sample in the indirect-light
  accumulation sub-pass after primary G-Buffer shading.
- Phase529: Probe relocation (move probes out of geometry via backface-hit heuristic).

### Future Enhancements

1. **Multi-bounce** — second probe grid sampled during trace (self-bounce, Majercik et al. §5).
2. **Probe relocation** — translate probes outside solid geometry (backface fraction threshold).
3. **Infinite irradiance fields** — sparse streaming grid (4 cascades), Lumen-style.
4. **World-space irradiance cache** (complement) — reuse probe data for specular GI seam fix.
