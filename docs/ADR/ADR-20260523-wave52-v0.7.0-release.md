# ADR-20260523 — Wave 52: v0.7.0 release tag (Phase 6 Sprint 2)

## Bağlam

Phase 6 Sprint 1 v0.6.0'da kapanmıştı (ADR-20260523-wave44). Aynı gece
kullanıcı "sabaha kadar bitmeyecek bir plan yap" istedi — Sprint 2,
Wave 45-51 ile devam etti. Bu ADR + tag Sprint 2'yi resmi olarak kapatır.

Sprint 1 zaten Phase 6 routing tablosunun parça parça kapanışıydı;
Sprint 2 networking + plugin + bench yüzeylerini "feature complete for
v1.0" seviyesine yaklaştırıyor.

## Karar

`v0.7.0` git tag'i atılır. Marathon devam ettiği için sınıf-0 release
değil — aynı tek-kişilik commit/push hattının snapshot'ı. 4/4 Windows
compiler × 54/54 ctest green (flaky cd_test_threadpool tek tekrar
denemede yeşil — Wave 51 öncesinden var, Sprint 2 kapsamı dışında).

Tag dev branch HEAD'ine. Master merge ayrı PR (v0.4/v0.5/v0.6 modelinin
devamı).

## Bu sürümde olanlar (delta v0.6.0 → v0.7.0)

### Phase 6 Sprint 2 waves (45-51)

| Wave | Library | Çıktı |
|---|---|---|
| Wave 45 | `cd::net::ReliableChannel` | RFC 6298 SRTT/RTTVAR adaptive RTO; Karn algoritması (retransmit RTT örnekleri atlanır); per-pending RTO doubling; clamp [rto_min, rto_max] |
