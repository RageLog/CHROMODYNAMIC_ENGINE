## Karar

### 65.A — `cd/net/SnapshotBuffer.hpp`
Template `<T>` snapshot buffer:
- `push(t, state)` — sorted-by-time insert.
- `sample(t)` — bracketing snapshots arasında linear lerp;
  clamp at edges. T `T + T` ve `T * float` desteklemeli.
- `drop_older_than(t)` — front'tan < t snapshot'ları siler.
- `clear` / `size` / `empty`.

Server fixed-tick state → client render-time interpolation
(standard FPS multiplayer pattern, ~100ms behind newest snapshot).

### 65.B — `cd/ecs/SystemGraph.hpp`
Named ECS system DAG + Kahn's topo sort:
- `add(name, depends_on)` — system + dependency list.
- `build_order()` → `{ order, has_cycle }`.
- Missing dep ignored (defensive).
- Cycle detection via order.size() != n test.

Inlined topo-sort algoritması — cd::ecs'in cd::framegraph'a depend
etmemesi için (layering violation olur).
