## Karar

### 52.A — `cd/shader/ShaderStageDesc.hpp`
Mevcut `cd::shader::ShaderStage` **enum class** olarak Compiler.hpp'de
zaten tanımlıydı (kVertex/kFragment/...). Yeni struct `ShaderStageDesc`
ile çakışmamak için adlandırma ayrıldı:
- `StageKind` enum class — Vulkan-style stage kindleri (vertex, fragment,
  compute, geometry, tess, RT raygen/closesthit/anyhit/miss).
- `Language` enum class — Glsl / Hlsl / Msl.
- `ShaderStageDesc { stage, language, entry_point, defines }` —
  compile-call site'larında tek-noktada bilgi.
- `from_glsl(s, entry="main")` / `from_hlsl(s, entry="main")` factory.
- `define(key, value="1")` ekler.
- `to_string(StageKind)` — debug + telemetri.

ShaderStage enum class'ı dokunulmaz; yeni desc tipi yan yana yaşıyor.

### 52.B — `cd/core/ProfileSpan.hpp`
RAII scope timer + global registry:
- `ProfileSpan { "name" }` ctor `steady_clock::now()` snapshot, dtor
  elapsed → `ProfileRegistry::instance().record(name, ns)`.
- `ProfileRegistry::stats("name")` → `{ total_ns, count }`.
- Mutex-korumalı (single-threaded fast-path için pahalı ama editor
  use-case için doğru).

Editor/asset baking sites'i ucuz `ProfileSpan _ { "scope_name" };`
ile araklamadan tek satır timing yapabilir.

### Naming collision lesson
Bir önceki ders (anon-ns include trap) artık yerleşti. Yeni keşif:
**aynı namespace içinde aynı isimle struct + enum class olamaz**
(ODR violation). `enum class ShaderStage` + `struct ShaderStage`
compile error veriyor. Çözüm: desc tipinin adına `Desc` suffix.

## Reddedilen alternatifler

- **ProfileSpan'da `std::high_resolution_clock`**: `steady_clock`
  monotonik garantili; high_resolution_clock implementasyona göre
  system_clock alias'ı olabiliyor (NTP zıplar).
- **Lock-free ProfileRegistry**: thread-local accumulator + frame-end
  merge daha hızlı. İlk versiyon mutex; gerek olunca refactor.
- **Mevcut ShaderStage enum class'ı genişletmek**: backward-compat
  ihlal ederdi. ShaderStageDesc ayrı tip → ilerideki API'nin temeli.
