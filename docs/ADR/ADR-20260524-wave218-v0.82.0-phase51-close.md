## Bağlam

Phase 51, marathon'un 54. minor release'i. Render katmanına post-process
chain veri yapısı + ECS katmanına lifecycle callback registry.

## Karar

### 51.A — `cd/render/PostProcessChain.hpp`
`PostProcessPass { name, enabled, params }` listesi. Methods:
- `add(name, params=0)` — insertion-order tutan vector'a ekler.
- `remove(name)` — silen find_if + erase.
- `set_enabled(name, on)` — toggle without remove.
- `enabled_view()` — yalnızca enabled pass'leri pointer'larıyla
  döner (renderer iter eder).
- `passes()` — full listeyi okumak için.

Rendere bağlı değil; binding tarafı renderer'ın iş yükü. Editor
inspector "Vignette: [x] Bloom: [x] FXAA: [ ]" UI'ı doğrudan bu yapı
üzerine binebilir.

### 51.B — `cd/ecs/Lifecycle.hpp`
Multicast callback registry:
- `on_created(fn)` / `on_destroyed(fn)` → HandleId.
- `remove(id)` — slot listesinden siler.
- `notify_created(e)` / `notify_destroyed(e)` — caller manuel çağırır.

World ile sıkı bağlı değil — caller create/destroy site'lerinde
notify yapar. Editor selection-on-create highlight, GPU resource
cleanup, audit logging gibi yan-effect zincirlerine ucuz extension.
