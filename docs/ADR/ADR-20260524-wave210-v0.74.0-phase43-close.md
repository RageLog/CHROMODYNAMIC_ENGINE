### 43.B — `cd/framegraph/PassTopology.hpp`
Kahn's algorithm topo-sort:
- Girdi: `node_count` + `edges (from, to)` listesi.
- Çıktı: `TopoResult { order, has_cycle }`.
- In-degree 0 nodes ready queue'a, FIFO pop, successor in-degree--.
- Output kısa → cycle.
- Out-of-range edge'ler sessizce drop edilir (defensive).

`std::queue<uint32_t>` ile stable FIFO sıralama (tie-break "first
pushed first popped"). FrameGraph zaten kendi pass DAG'ını tutuyor;
bu primitive job-scheduler, asset-cook DAG, ve gelecekteki
multi-renderer dependency çözümünde de kullanılabilir.

## Reddedilen alternatifler

- **Tarjan's SCC**: cycle tespiti için doğru ama overkill — tek-cycle
  varlığı bilmek yeterli, hangi node'ların cycle'da olduğu burada
  gerekmez.
- **Templated `topo_sort<T>` generic node type**: `uint32_t` ID
  yeterli; caller mapping tablosunu kendi tutar (FrameGraph zaten
  bunu yapıyor — pass index ↔ pass struct).
