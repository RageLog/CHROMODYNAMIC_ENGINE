## Reddedilen alternatifler

- **sol3 / LuaBridge vendor:** Daha güçlü bindings ama 5+ external dep.
  cd::script self-contained kalsın diye doğrudan Lua C API üzerine
  ince bir wrapper.
- **Lua 5.3 / LuaJIT:** 5.4 stable since 2020-06; bit-exact integer
  semantics + generational GC. LuaJIT ARM/x86_64 binary code-gen +
  yüksek bakım, scripting MVP için overkill.
- **WASM (WAMR):** Daha sonra için saklanıyor. Lua öğrenme eğrisi <
  WASM toolchain karmaşası; ilk binding katmanı için doğru.

## Açık sorular

* **Args / return values from call_global:** Şu an no-arg / no-return.
  Game-logic patterns için type-erased tuple + lua_push... + lua_to...
  zinciri eklenebilir. Sprint 7+ wave candidate.
* **Sandboxing (memory + step caps):** Engine her örnek kendi
  lua_State'ine sahip ama execution time / memory limit yok. Untrusted
  script çalıştırılacaksa lua_setcstacklimit + lua_sethook(LUA_MASKCOUNT)
  ile sınırlandırılmalı. Sprint 7+ candidate.
* **Lua module loading (require):** Şu an `package.path` default'ları
  geçerli; bunu Engine'a ait sandboxed module path olarak eklemek
  Sprint 7+ candidate.
