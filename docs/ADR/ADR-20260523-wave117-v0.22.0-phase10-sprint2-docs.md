# ADR — v0.22.0 / Wave 117 — Phase 10 Sprint 2 (Docs leg complete)

- Date: 2026-05-23
- Status: Accepted
- Wave: 117
- Tag: v0.22.0

## Context

v0.21.0 closed Sprint 1 (Quality leg). Sprint 2's stop condition (per
Wave 106's ADR) is:

> The engine surfaces a navigable docs site: high-level architecture
> doc, per-tier modules in the Doxygen sidebar, and a README that
> matches reality.

Three waves landed between v0.21.0 and v0.22.0 to satisfy that:

- **Wave 114** `docs/ARCHITECTURE.md` — long-missing canonical
  architecture overview. Stack diagram (Application → Runtime → UI →
  World → Render → Asset → Foundation, plus the side libraries
  `cd::script` and `cd::imgdiff`), tier-collapsed dependency DAG in
  mermaid form, cross-cutting conventions (error handling via
  Result + diag + format, ownership rules, C++ surface incl. the
  noexcept-honesty lesson, build flags, test discipline), build + test
  loop entrypoints, and the seven-step checklist for adding a new
  subsystem (with the @ingroup registration as the closing step).
- **Wave 115** README surgical refresh — Phase status banner now
  reflects the actual progress through Phase 9 + Phase 10 Sprint 1;
  counts corrected (55 libraries, 40 samples, 58 test binaries);
  Architecture and Documentation sections link the new
  ARCHITECTURE.md, CHANGELOG.md, and Modules.dox; stale per-sample
  expected counts removed.
- **Wave 116** `@addtogroup` opt-in pass on foundation public headers
  — ErrorCode / ErrorFormat / Result / Assert / RingBufferSink /
  PanicDump now wrap their namespace declarations so they bind into
  the Modules.dox hierarchy. Zero-warning Doxygen 1.16.1 build.

## Decision

Tag **v0.22.0**, closing Phase 10 Sprint 2 (Docs leg). The Foundation
tier now has the canonical mental-model document (ARCHITECTURE.md),
the README accurately describes what the engine is in this branch,
and the foundation symbols join the Doxygen group tree via opt-in
`@addtogroup` brackets.

## Rejected alternatives

- *Wait for full per-symbol @ingroup annotation before tagging.*
  Rejected: that's a long tail of polish that doesn't gate the Sprint 2
  stop condition. The group hierarchy + foundation opt-in is enough
  for the sidebar to be useful; remaining tiers can opt in incrementally
  in Sprint 3+ without holding the release.
- *Rewrite README from scratch.* Rejected: the existing README has
  good detail on toolchains, presets, and sanitizer commands.
  Surgical updates kept what was correct and replaced only the bit-
  rotted status / counts / link sections.
- *Wait for Doxygen 1.17 to fix the bracketing depth issue.*
  Rejected: the page hierarchy is already navigable in 1.16.1, and
  Sprint 2 doesn't depend on full member listing depth — that's a
  polish item, not a stop condition.

## Consequences

- Phase 10 Sprint 2 stop condition met. Sprint 2 closes.
- Sprint 3 (CI / Platform leg) opens next: Linux + macOS runner
  expansion (the README claims them green but the matrix is currently
  Windows-only), perf-CI gate, and platform-specific test runs.
- v0.20.0 → v0.21.0 → v0.22.0 → … → v1.0.0 path still on track.
- All 58 ctest targets remain green on ninja-debug.
- Documentation pipeline produces zero warnings on Doxygen 1.16.1.
