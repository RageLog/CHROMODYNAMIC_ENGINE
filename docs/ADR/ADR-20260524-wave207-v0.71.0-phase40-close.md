# ADR-20260524 wave207 — v0.71.0 Phase 40 close

## Bağlam

Phase 40, marathon'un 43. minor release'i. Net katmanına dedup penceresi
ve concurrency katmanına spinlock-friendly exponential backoff eklendi.

## Karar

### 40.A — `cd/net/SequenceWindow.hpp`
UDP paketler için sliding-window duplicate detection. `latest_` + 64-bit
bitmask. `accept(seq)`:
- İlk paket → kabul.
- `seq > latest_` → ileri kayar; eski bit'ler shift edilir; eski
  `latest_` mask'e işlenir.
- `seq <= latest_` → pencere içindeyse bit kontrolü, oluşmadıysa
  işle + kabul.
- Pencere dışı veya tekrar → red.

Template `N ∈ [1,64]` parametresi ile pencere boyu seçilir (default 64).
ChannelMux reliable-channel'ının ack/dedup işini bu primitive ile yapar.

### 40.B — `cd/concurrency/Backoff.hpp`
Intel "Restless Multi-Lock" şablonu:
- Step 0..4: 1..16 iter pause/yield instruction (x86 `_mm_pause`,
  diğer mimaride volatile loop body).
- Step 5..9: `std::this_thread::yield()`.
- Step ≥10: `sleep_for(step microseconds)`.
- Step cap'i 20.

Spin-lock contention'da, lock-free CAS retry loop'unda, asset thread
worker yield'inde kullanılır.

## Reddedilen alternatifler

- **Replay window büyütmek (64 → 256)**: 50ms RTT 60Hz oyunda ~3
  packet pencere fazlasıyla yeter; 64 bit tek register kontrolü
  korur.
- **Backoff için CPUID-tabanlı `_tpause` (Tremont/Lakefield)**:
  cross-platform değil; ihtiyaç olduğunda backend göndeririz.
