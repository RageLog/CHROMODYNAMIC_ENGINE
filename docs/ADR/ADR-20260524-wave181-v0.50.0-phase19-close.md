# ADR — v0.50.0 / Wave 181 — Phase 19 close (halfway-to-v1.0)

- Date: 2026-05-24
- Status: Accepted
- Wave: 181
- Tag: **v0.50.0** — psychologically halfway-to-v1.0 (v1.0 gate
  itself remains user-only per the rollback ADR).

## Sub-phases shipped

### 19.E — `cd::scene::ParticleSystem`
Header-only fixed-pool emitter. `spawn(pos, vel, lifetime)` +
`tick(dt, gravity)` with constant-acceleration integration. Pool
size at construction; full pool returns false from spawn. 3 unit
tests pin spawn / pool-exhausted / tick-advance behavior.

### 19.F — `cd::anim::blend2`
Two-pose linear blend with NLERP-renormalize quaternions
(walk↔run blend shape). 4 unit tests pin zero-weight (=A),
full-weight (=B), half-weight (=midpoint), mismatched-size
fail.

### 19.G — `cd::scene::LodSelector`
Distance-threshold LOD selector. Sorted threshold array →
`select(distance)` returns the active LOD index. `force()` /
`unforce()` override for editor inspection. 2 unit tests pin
three-LOD selection + force override.

### 19.A / 19.B / 19.C / 19.D — deferred to Phase 20

Vulkan TLAS, AMD CI workflow, editor selection outline, job
priority bench. Marathon discipline applies — three solid
header-only primitives shipped instead of six half-finished
items.
