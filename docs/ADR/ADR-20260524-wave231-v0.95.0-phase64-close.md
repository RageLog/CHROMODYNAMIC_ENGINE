### 64.B — `cd/concurrency/JobToken.hpp`
Cooperative cancellation token:
- `JobToken` lightweight handle, shared `std::shared_ptr<State>`.
- `cancel()` / `complete()` — caller signals.
- `is_cancelled()` / `is_complete()` / `is_settled()`.
- `wait()` — blocks until either fires.

Long-running asset bake / streaming worker'ları poll edip nazikçe
çıkar.
