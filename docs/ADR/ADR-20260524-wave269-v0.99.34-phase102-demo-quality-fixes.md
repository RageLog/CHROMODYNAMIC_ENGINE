# ADR-20260524 / Wave 269 / v0.99.34 / Phase 102 — Demo Quality Fixes

## Status
Accepted — 2026-05-24

## Context

During the live demo-reel walkthrough following Phase 101, the user
spotted two visible regressions that the existing test suite + golden
captures had not surfaced:

1. **`hello_pbr` looked like plastic.** The 5×5 metallic/roughness
   sweep grid rendered all 25 spheres as nearly identical mid-bej
   blobs. The metallic axis (X) was effectively invisible — chrome
   (metallic=1) and dielectric (metallic=0) read the same. The
   shader already implemented Cook-Torrance + GGX + Schlick + Smith G,
   but three issues collapsed the visual signal:
   - **No IBL ambient.** Metallic surfaces had nothing to reflect off
     a pitch-black background, so the Fresnel rim disappeared.
   - **Single hot key light (intensity 4.0).** Reinhard tonemap
     saturated highlights to white, erasing the Fresnel tint.
   - **No skybox.** Background was a solid dark color (clear → present).
     The user explicitly asked: *"gokyuzu yok bunuda duzeltirmisin"*.

2. **`hello_editor` Inspector panel was unreadable.** The user
   reported: *"sag taraftaki kontrolleri kullanmmak cok zor. sekille
   isimler karsilabnmiyor"* (controls on the right are hard to use,
   widgets and labels collide). The Inspector was docked into a
   380 px right column with default ImGui `InputFloat3` widgets that
   place their label to the right of the three X/Y/Z mini-boxes.
   At 380 px the label column ran out of space and the buttons
   wrapped onto the next line.

Both are pure-sample fixes — no engine-library change beyond the
Compressor.hpp warning fix already landed in Phase 101.

## Decision

### `hello_pbr` — overhaul shader + scene for real PBR readout

Five-pass evolution captured here as the final state:

1. **3-light rig** in the fragment shader: warm key (push-constant
   driven, intensity 0.9), cool fill (0.30 × key), warm back-rim
   (0.55 × key). Direct light contribution sums three Cook-Torrance
   lobes via a `direct_lobe(...)` helper.

2. **Analytical-sky split-sum IBL** ambient (no precomputed cubemap,
   no BRDF LUT). `sample_env(dir)` returns the same 3-band palette
   `hello_skybox` uses (zenith 0.18,0.42,0.85 → horizon
   0.78,0.86,0.96 → ground 0.10,0.10,0.14). Diffuse irradiance ≈
   env sampled along N; specular reflection ≈ env along R, blurred
   toward N as roughness rises. Roughness-aware Fresnel
   (Lazarov / Karis 2013) gates the specular contribution so rough
   metals don't over-reflect.

3. **Real skybox pass** drawn first in the same render pass: a
   fullscreen-triangle pipeline with `depth_test=depth_write=false`,
   reusing `sample_env` plus a sun disk co-located with the warm key
   light. Clear color set to magenta as a regression tripwire — if
   the sky pass ever stops running, the bug is immediately visible.

4. **ACES Narkowicz tonemap** in both the sphere and sky fragment
   shaders. Reinhard crushed Fresnel tint into white at intensity 0.9
   or higher; the five-coefficient ACES fitted curve (Narkowicz 2015)
   keeps highlight chroma readable while still landing peak luminance
   under 1.0.

5. **Warm copper albedo (0.95, 0.64, 0.32)** instead of neutral
   white. With a neutral albedo, F0 for metallic=1 equals white and
   the Fresnel highlight color matches dielectric — there's no
   tinted-vs-untinted spec to distinguish the two ends of the
   metallic axis. Copper makes the Fresnel rim unmistakably orange
   on the right column and unmistakably white on the left.

### `hello_editor` — restructure Inspector layout

- Widen the inspector docking column from 380 → 480 px.
- For every transform field (Position / Scale / Rotation), wrap with
  `ImGui::SeparatorText("...")` so section headers are visually
  distinct, not just thin separators.
- Split label and widget into two ImGui calls:
  - `ImGui::Text("delta XYZ")` on its own line (the "isim")
  - `ImGui::InputFloat3("##trans", ...)` directly below with the
    label hidden via `##` (the "şekil")
- Apply buttons get a fixed 120 px width (consistent across the
  three sections) plus a trailing `SmallButton("0##t")` / `("1##s")` /
  `("0##r")` for one-click reset.
- `PushItemWidth(content_avail * 0.62F)` so the three numeric mini-
  boxes get a stable 62% of available width and never collide with
  the right edge.

## Rejected alternatives

- **Switch tonemap globally to filmic Hejl 2015.** ACES is fine for
  this demo; a global switch would touch every other sample and
  isn't in scope.
- **Pre-bake a real cubemap for IBL.** Phase 17 already has BLAS
  construction landed and a prefiltered cubemap pipeline is on the
  pending list; until then the analytical-sky split-sum is the
  cheapest stand-in that makes the metallic axis readable.
- **Per-row distinct metal albedos (copper / gold / silver / iron /
  aluminum).** This is how Sketchfab and production engines's PBR table is
  organized, but it breaks the "axes = pure parameters" semantics of
  this specific demo. Kept one albedo so the X = metallic and
  Y = roughness reading stays unambiguous.
- **Custom ImGui widget for "labelled vector input"** instead of
  the `Text(...) + InputFloat3("##id")` two-call pattern. Worth
  considering when more panels need the layout, but the inline
  pattern is the minimum delta that fixes this Inspector.

## Consequences

- `hello_pbr.exe` now opens with a skybox, three-light rig, sky-tinted
  IBL ambient, and an unambiguous metallic gradient.
- `hello_editor.exe` Inspector panel reads cleanly: each field shows
  its own section header, label-then-widget, and a 120 px Apply +
  reset side-button.
- Sample-side changes only — engine libraries untouched.
- Golden-capture path remains the same (`schedule_golden_capture`
  still runs on the last headless frame).

```
    cd_sample_hello_pbr cd_sample_hello_editor

./build/llvm-win-base/bin/Debug/hello_editor.exe     # user-confirmed
```

User confirmed the skybox + metallic axis legibility on the v5 pass
and accepted the editor layout after the widening + label split.
