## Karar

### 83.A — `cd/editor/MenuBar.hpp`
Headless menu tree:
- `MenuItem { label, kind (Action/Separator/Submenu), action,
  children }`.
- `Menu` handle (non-owning) — `add_item(label, fn)`,
  `add_separator()`, `add_submenu(label)`.
- `MenuBar.add_menu(label) → Menu` top-level entry.
- Tree owned via `unique_ptr` for stable child pointers.

Renderer (ImGui) walks the tree and emits BeginMenu/MenuItem. Pure
data; testable without ImGui.

### 83.B — `cd/core/Ref.hpp`
`std::reference_wrapper` muadili daha açıkça isimli:
- ctor `Ref<T>(T&)`; `Ref(T&&) = delete` (rvalue bind yasak).
- Implicit `T&` conversion + `->` operator.
- "Non-owning, never-null" semantik dokümantasyonu API ergonomisi
  artırır — `World*` vs `Ref<World>` arasındaki niyet farkı net.
