# ADR-20260524 / Wave 276 / v0.99.41 / Phase 111 — CommandPalette wired into hello_editor

## Status
Accepted — 2026-05-24

## Context

Phase 31 shipped a headless `cd::editor::CommandPalette` (FZF
subsequence scoring + callback registry) but no editor sample
actually used it interactively. hello_command_palette (Phase 101)
demonstrated the matcher via stdout. The editor frontend stayed
button-driven.

## Decision

Wire the palette into `hello_editor`:

- Construct a single `CommandPalette` at startup and register eight
  representative commands covering the editor's existing actions
  (Undo, Redo, Clear History, Select Cube/Sphere/Cone, Reset
  Selected, Toggle Auto-Spin, Help: Print Shortcuts). Each command
  captures the editor's mutable state (`history`, `entities`,
  `selected`, `log_push`) via lambda &-capture.
- Add a `palette_visible` bool + a `palette_query` string buffer.
- Hotkey: `Ctrl+Shift+P` toggles the palette. Modifier state read
  from `ImGuiIO::KeyCtrl / KeyShift` (the OSEvent layer doesn't
  carry mod-bitmask). `Esc` closes the palette first; only on the
  second Esc does the app quit.
- Render: an ImGui popup pinned to top-centre when visible. The
  query InputText auto-focuses on appear; filter results render as
  `Selectable` rows; Enter on first match fast-paths to invoke.

## Rejected alternatives

- **Modal popup via `ImGui::OpenPopup`.** Cleaner ImGui idiom but
  popups absorb focus and Esc behaviour gets tangled with the
  app's quit handler. Flat `Begin("Command Palette")` + custom
  position is simpler.
- **Custom KeyChord matcher from `cd::input::KeyChord` here.**
  The hotkey logic is one if-statement on `io.KeyCtrl && io.KeyShift`;
  pulling in cd::input would add a dependency for one match. The
  KeyChord primitive is still where multi-chord hotkeys belong;
  this single-hotkey case doesn't need it yet.
- **Pre-built shortcut table UI.** A registry of "command id ↔
  key chord" with auto-rendered help screen — out of scope. Phase
  31's palette is the keyboard-friendly path already.

## Consequences

- hello_editor gains a discoverable command surface without
  bloating the toolbar.
- Future editor actions (selection outline toggle, gizmo mode
  switch, etc.) can register a palette entry instead of competing
  for toolbar real estate.
- `int selected` declaration moved up the file to before palette
  registration so the `[&]` capture sees it. Harmless reorder.

## Validation

```
cmake --build --preset llvm-win-debug --target cd_sample_hello_editor
./build/llvm-win-base/bin/Debug/hello_editor.exe
# Ctrl+Shift+P → palette opens → type "sel" → "Select: Cube" / "Sphere" / "Cone"
# Enter fires the top hit, palette closes, selection in the Scene list updates.
```
