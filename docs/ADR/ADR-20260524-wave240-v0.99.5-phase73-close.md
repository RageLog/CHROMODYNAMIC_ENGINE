### 73.B — `cd/asset/BundleMeta.hpp`
32-byte fixed-size `BundleHeader`:
- `magic` (CDMS/CDTX/CDSN), `version`, `flags`.
- `payload_size`, `payload_crc32`, `asset_count`.
- `reserved` field padding to 32-byte.
- `static_assert(sizeof == 32)`.
- `is_valid_header(h, magic, max_size=1<<32)` magic + version +
  size + asset_count > 0 sanity check.

Asset bundle (cdmesh/cdtex/cdscene) wire-format prelude. CRC32
field Phase 35 codec ile birlikte bütünlük kontrolü için.
