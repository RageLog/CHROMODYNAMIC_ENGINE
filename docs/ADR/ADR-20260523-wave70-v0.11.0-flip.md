## Phase 7 routing — ilerleme

Kullanıcının "kolaydan zora, genelden özele" sırası:

1. **Full FLIP perceptual diff** ✓ **CLOSED (Sprint 6, v0.11.0)** — FLIP-lite ile
   pratik düzeyde tamamlandı. Tam paper (chroma channels + frequency-
   domain CSF + edge/point) Sprint 6+ wave'lerine kalabilir ama
   regression-triage için yeterli.
2. **Scripting tier (Lua)** — Sprint 7 başlangıç. Lua 5.4 via
   FetchContent + minimal binding layer. ~6-8 wave.
3. **Real CoreAudio + ALSA + 3D positional** — Sprint 8. CI runner
   sorunu hâlâ açık; lokalde compile validation + 3D math test
   ediliyor.
4. **Forward+ / clustered light culling** — Sprint 9. Mimari ADR +
   Vulkan compute shader; en büyük scope.
