# ADR-20260524 wave202 — v0.66.0 Phase 35 close

## Bağlam

Phase 35, io ve asset katmanlarına bütünlük-tahkik (integrity) ve
tagging primitive'leri ekler.

## Karar

### 35.A — `cd/io/Crc32.hpp`
CRC-32/IEEE (zlib/png/Ethernet polynomial 0xEDB88320). 256-entry
lookup tablosu `consteval` ile derleme zamanı oluşturulur — runtime
init yok. İki form:
- `crc32(span)` one-shot
- `Crc32` class — `update()` + `value()` ile streaming

Asset bundle integrity, save-file checksum, lightweight hash key
kullanımı için. **Cryptographic değil**; bunu doc'a yazdık.

### 35.B — `cd/asset/AssetTag.hpp`
32-bit FNV-1a hash'i sarmalayan `AssetTag` struct + sıralı
`AssetTagSet`. Etiket sayısı asset başına küçük olduğu için
(beklenen ≤ 16), unordered_set yerine sorted vector + binary_search
seçildi — cache locality kazanır.

Editor "tier3 enemy in level 4" gibi multi-tag query yapar; hot-reload
scope'u tag-filtered çalıştırılabilir.

## Reddedilen alternatifler

- **xxHash / CityHash**: daha hızlı ama header-only port + lisans
  sürtüşmesi var; CRC-32 + FNV-1a yeterince hızlı + zero-dep + standart
  test vektörleri ile doğrulanabilir.
- **AssetTag string saklamak**: editor tooltip'inde label görmek
  gerekiyorsa ayrı registry (hash → label) yapılabilir; tag-hash'in
  kendisi label taşımak zorunda değil (asset metadata'da kalsın).
- **CRC-32C (Castagnoli)**: CPU intrinsic ile çok daha hızlı ama
  cross-platform tutarlılık zorlaşır (ARM CRC32 instruction vs SSE 4.2
  ayrı opcode). Pure-table IEEE her yerde aynı bit.
