# ADR-20260523 — Wave 106: Phase 10 mimari — v1.0 path

## Bağlam

Phase 8 routing tablosunun tamamı (7/7 item) Wave 105 ile resmen
kapandı. Phase 9 networking (Sprint 1, Wave 99) + Forward+ GPU
(Sprint 2, Wave 101-103) tamamlandı. Phase 9 routing tablosunda
kalan item'lar (Metal/D3D12 concrete impl, render-graph reorg,
editor polish, perf CI) ya platform CI runner gerektiriyor ya da
büyük scope refactor.

Marathon istatistik özeti at v0.19.0 + Wave 105:
- 82 wave (Wave 23 → 105)
- 15 release tag (v0.2.0 → v0.19.0)
- 55 engine library, 39 sample, 5 tool, 4 CI workflow
- ~300 internal test case
- 4/4 Windows compilers green her tag'de

Bu noktada engine "feature complete for v1.0 baseline" durumda;
kalan iş POLISH + DOCS + STABILITY + RELEASE PATH. Bu yeni iş
karakter olarak feature delivery'den farklı: kod yazmaktan çok kod
gözden geçirmek, dokümantasyon yazmak, API mühürlemek, sürüm
yönetimini sıkılaştırmak.

## Karar

**Phase 10 = "v1.0 path"** — feature freeze + polish + stability +
release-readiness. Sprint paneli:

### Sprint 1 — Quality leg (Wave 107)

| İş | Çıktı |
|---|---|
| cd::diag enhancements | Assertion macros (CD_ASSERT, CD_VERIFY); error stack-trace formatting; structured panic hook |
| API stability survey | Public API audit; her header'da "stable since vX.Y" + "experimental" işaretleri |
| -Werror tightening | Pre-existing clang-tidy warnings cleanup (`readability-braces`, `readability-isolate-declaration`, etc.) |

### Sprint 2 — Docs leg

| İş | Çıktı |
|---|---|
| Doxygen pass | Public header'larda eksik @brief / @param / @return / @note tamamla |
| User-facing README | Engine getting-started, sample tour, build matrix |
| ARCHITECTURE.md | Library DAG, public surface, design principles |
| API examples per library | her library için en az 1 minimal usage snippet |

### Sprint 3 — CI / Platform leg

| İş | Çıktı |
|---|---|
| Linux runner expansion | inotify FileWatcher + ALSA backend + Vulkan headless validate |
| macOS runner expansion | FSEvents + CoreAudio + Metal compile gate |
| Perf regression CI step | Wave 65 workflow → bench gate becomes hard PR check |
| Doxygen artifact upload | docs.yml → GitHub Pages publish |

### Sprint 4 — Release path

| İş | Çıktı |
|---|---|
| CHANGELOG.md cleanup | Marathon CHANGELOG re-format; sürüm başlıkları + tarihler standardize |
| v1.0.0-rc.1 tag | Release candidate; community feedback window |
| CMake package config | install/ + cd_targets.cmake export for downstream consumers |
| `find_package(CHROMODYNAMIC)` smoke | Downstream-project sanity check |
| v1.0.0 GA | Final tag after RC feedback |

## Reddedilen alternatifler

- **Phase 9 Sprint 3-8 hepsini bitir, sonra v1.0:** Metal/D3D12
  concrete implementations CI runner expansion'a bağlı; marathon
  hostunda gerçek test imkansız. Skeleton + ADR yeterli; bu
  item'lar Phase 11+ candidate.
- **Yeni feature kümeleri (ray tracing, mesh shaders, sparse
  resources):** v1.0 baseline'ın altında değil üstünde; v1.x
  minor bump'larında ele alınabilir. v1.0'a polish + docs +
  stability getiriyor.
- **v0.X.0 marathon'unu sonsuza dek devam ettir:** Feature
  surface 55 library + 39 sample. Daha fazla feature
  eklemekten daha çok değer: mevcut surface'i v1.0 olarak
  mühürleyip downstream tüketim hâline getirmek.

## Sonuçlar

Phase 10 açılır. Sprint 1 başlangıç (Wave 107) = cd::diag
enhancements + assertion macros. Marathon temposu yavaşlıyor —
yeni feature wave'leri yerine polish + docs + CI iş.

## Açık sorular

- **Phase 10 toplam wave sayısı:** Sprint 1-4 × 2-4 wave/Sprint =
  8-16 wave. v1.0 tag'i Wave 115-125 civarı tahminen.
- **v1.0 backward-compat söz:** API stability survey hangi
  surface'leri "stable since v1.0" olarak kilitler? cd::core,
  cd::math, cd::mem, cd::time temel; cd::ecs, cd::scene, cd::rhi
  feature complete; cd::editor / cd::editor_ui experimental
  durmuş olabilir.
- **Pre-built artifact dağıtımı:** v0.4.0 ADR'sinde açık olan
  GitHub Release artifact item'ı. Phase 10 Sprint 4'te
  CPack'le birlikte yapmak mantıklı.
