### 56.B — `cd/math/Statistics.hpp`
Online accumulator:
- `add(x)` — Welford algorithm; numeric-stable mean + variance.
- `mean()` / `variance()` / `stddev()` / `min()` / `max()` /
  `count()` / `reset()`.

Welford'un katastrofik cancellation problemine karşı dayanıklılığı
büyük örneklem + yakın-mean dağılım için kritik. ProfilerView frame
time histogramı, telemetry pipeline aggregator, jitter raporu için.
