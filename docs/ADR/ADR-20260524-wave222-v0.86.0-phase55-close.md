## Karar

### 55.A — `cd/audio/Mixer.hpp`
Template `Mixer<N=8>`:
- `set_gain(ch, g)` (negative gain → 0 clamp).
- `mix(ch, x)` — `acc += x * gain[ch]`.
- `pull()` — accumulator döner ve sıfırlar.
- `gain(ch)` getter.
- Out-of-range channel sessizce ignore.

DSP graph node'larının çoklu source'lerini tek mono bus'a toplar
(music/sfx/voice/ambient). `Limiter` (Phase 41) bus output'una pipeline'da
takılır.

### 55.B — `cd/asset/HotReloadQueue.hpp`
FileWatcher event coalescing:
- `notify(id)` — dirty set'e ekle (duplicate insert no-op).
- `is_pending(id)` — pending mi?
- `drain(fn)` — her dirty asset için fn çağır, sonra set clear.
- `pending_count` / `clear`.

Storage `unordered_set<uint64>` — std::hash<AssetId> şartı yok.
Text-editor save-on-keystroke firtinasına karşı asset reload
deluge'unu önler.
