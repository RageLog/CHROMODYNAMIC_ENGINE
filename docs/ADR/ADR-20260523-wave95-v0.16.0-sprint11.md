## Reddedilen alternatifler

- **Wave 92 sandbox: lua_setallocf memory cap:** lua_sethook count cap
  CPU sınırı verir; bellek cap için lua_setallocf ile özel allocator
  yazmak gerekir. Memory bomb attack için CPU cap çoğunlukla yeterli
  (sonsuz string concat → sonsuz instruction). Phase 8+ candidate.
- **Wave 94: gerçek frequency-domain CSF (FFT):** Spatial-domain
  Gaussian approximation pratik düzeyde yeterli (yine Mullen 1985'in
  chromatic CSF curve'ünü Gaussian σ ile fit ediyor). Full FFT-based
  Andersson CSF Phase 8+ candidate.
- **Volumetric fog GPU compute (froxel-grid):** Forward+ Vulkan
  wiring tamamlandığında ek bir compute pass. CPU baseline doğru
  cevabı veriyor — GPU port ertelendi.
