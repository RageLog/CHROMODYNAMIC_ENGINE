# ADR-20260524 wave199 — v0.63.0 Phase 32 close

## Bağlam

Phase 32, editor ve ui katmanlarına UX seviyesi primitive'leri ekler:
fuzzy command palette ve anchor-bazlı layout solver. Her ikisi de
rendering-agnostic, header-only.

## Karar

### 32.A — `cd/editor/CommandPalette.hpp`
VS Code / Sublime palette mantığı. `register_command(id, label, action)`
ile additive registry. `filter(query)` FZF tarzı case-insensitive
subsequence scoring döner:
- temel match +1
- ardışık match bonus +2
- kelime başında match bonus +3 (boşluk/`_`/`-` sonrası)

`invoke(palette_index)` callback'i tetikler. Render hiç yok — caller
ister ImGui, ister terminal UI ile çizer. Aynı registry hem editor
hem CLI tool'unu beslesin diye.

### 32.B — `cd/ui/Anchor.hpp`
Godot Control / Unity RectTransform muadili: parent rect içinde
normalized (min_x, min_y, max_x, max_y) + pixel offset_min/offset_max.
`stretch()` full-bleed, `center(w, h)` sabit boyutlu ortalı kısayolları.

`resolve(parent, anchor)` → `Rect` (int32 piksel, float drift yok).
ImGui zaten kendi layout'unu yapar; bu primitive non-ImGui UI yolu
(terminal UI, custom HUD, dropdown popup) için.

## Test

- CommandPalette: EmptyQueryReturnsAll, FuzzyFindsSubsequence,
  NoMatchReturnsEmpty, InvokeFiresAction, ReRegisterOverwrites — 5 case.
- Anchor: StretchFillsParent, CenterPlacesFixedRect,
  OffsetMarginShrinksFromEdges, NestedParentOriginRespected — 4 case.

clang-cl + MSVC STL uyumluluğu için `test_editor.cpp`'de `<algorithm>`
en başa alındı (MSVC 14.50 `__msvc_heap_algorithms.hpp` clang-cl
altında qualified-name diagnostic'ine takılıyor — bilinen sorun, header
sırasıyla giderildi).

`ctest --preset ninja-debug` → **58/58 PASS**.

## Reddedilen alternatifler

- **CommandPalette içine ImGui drawer**: render katmanını editor'a
  pin'lerdi. Headless tutarsak CLI ve terminal UI'a aynı palette
  satılabilir.
- **Smith-Waterman scoring**: optimum ranking ama overkill. FZF
  benzeri subsequence + boundary boost yeterli.
- **Anchor için float Rect**: ImGui zaten float kullanıyor;
  non-ImGui yolu int piksel pin'lemekte yarar var (yüksek-DPI scale
  caller'da bilinçli uygulansın).
