# ADR-20260524 wave203 — v0.67.0 Phase 36 close

## Bağlam

Phase 36, ECS API'ye tag-component sugar'ı ve platform katmanına
deterministic-time primitive'i ekler.

## Karar

### 36.A — `cd/ecs/TagHelpers.hpp`
Empty-struct tag component'ler için API sugar:
- `tag<Tag>(world, entity)` — `world.emplace<Tag>(e)`
- `has_tag<Tag>(world, entity)` — `world.get<Tag>(e) != nullptr`
- `untag<Tag>(world, entity)` — `world.remove<Tag>(e)`

Sıfır ek depo (mevcut ComponentStorage sparse-set'i kullanır, EBO ile
zero-byte payload). Niyetin okunabilirliğini artırır — "tag(world, e)"
"emplace<Selected>(world, e)"den çok daha doğru hissettiriyor.

`Selected`, `Disabled`, `Frozen`, `Hidden` gibi editor / runtime
durum bayrakları için.

### 36.B — `cd/platform/StableTime.hpp`
`std::chrono::steady_clock` üzerine ince singleton wrapper:
- `monotonic_seconds()` — process açılışından beri f64 saniye, NTP /
  DST düzeltmesinden etkilenmez.
- `begin_frame()` — frame epoch'unu reset eder.
- `frame_epoch_seconds()` — `begin_frame()`'den beri f64 saniye.

Editor edit-history timestamp'leri ve replay-diff için: çağrı sayısına
bakılmaksızın aynı zaman tabanı. Singleton tek noktada anchored —
"hangi anda başlasak baseline farkı olur" hatası ortadan kalkar.

`ctest --preset ninja-debug` → **58/58 PASS**.

## Reddedilen alternatifler

- **TagHelpers'ı World metodu yapmak**: World tipi şişiyor; free
  function template aynı sonucu daha küçük header yüküyle veriyor
  (translation unit başına include daha hızlı parse).
- **StableTime için `std::chrono::system_clock`**: NTP düzeltmesi
  / DST geri zıplamalarına karşı dayanıksız; replay-determinism
  ihlal eder. Steady clock garanti.
- **Thread-local StableTime**: editor / job thread'leri farklı
  zaman tabanına bakar, replay diff kırılır. Single anchor doğru
  seçim.
