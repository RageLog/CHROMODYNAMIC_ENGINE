## Karar

### 59.A — `cd/input/GamepadState.hpp`
- `GamepadButton` enum: A/B/X/Y, LB/RB, Start/Back, LStickDown/RStickDown,
  Dpad up/down/left/right — bitmask `std::uint32_t` üzerinde.
- `GamepadState`: 4 stick float (left/right xy), 2 trigger float,
  `buttons` u32, `connected` bool.
- `is_button_down(state, GamepadButton)` predicate.
- `apply_deadzone(x, y, deadzone=0.15)` — radial deadzone, edge'i 0'a
  haritalar, unit-circle'ı unit-circle'a.

Platform layer (Win32 XInput / Linux evdev / iOS GCKeyboard) bu
struct'ı doldurur; gameplay code aynı tipten okur.

### 59.B — `cd/concurrency/EventBus.hpp`
Typed pub-sub:
- `subscribe<T>(fn)` → HandleId.
- `publish<T>(e)` — registered handlers'ı çağırır.
- `unsubscribe(id)`.
- **Single-threaded** — locking yok, caller coordinate eder. Cross-thread
  için Channel (Phase 57).

Game systems loose-coupling için: ECS → audio "EntityDestroyed",
player input → ui "MenuOpen", asset → editor "AssetReloaded".

## Reddedilen alternatifler

- **GamepadState'i ECS component yapmak**: input state'i singleton
  context; ECS layer'a tek-component encode etmek katlanabilir
  parametre genişler.
- **EventBus internal mutex**: thread-safe pub-sub kullanım kalıpları
  çağırma sitelerine göre değişir (lock convoy vs lock-free vs
  per-subscriber thread-local queue). Channel zaten cross-thread için.
