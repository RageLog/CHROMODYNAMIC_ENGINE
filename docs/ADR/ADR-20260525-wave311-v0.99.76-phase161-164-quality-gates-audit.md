# ADR Wave-311 — WAVE G quality-gates audit (v0.99.76)

- **Date:** 2026-05-25
- **Status:** Accepted
- **Predecessor:** [ADR-20260525-wave310-v0.99.75-phase155-156-157-wave-f-deferral](./ADR-20260525-wave310-v0.99.75-phase155-156-157-wave-f-deferral.md)
- **Successor:** ADR Wave-312 (WAVE H — Linux/macOS/mobile platform decision)
- **Tag:** v0.99.76

## Context

WAVE G of the marathon listed four quality-gate phases:

- Phase 161 — CI workflow MSVC + Clang-cl
- Phase 162 — ASAN/UBSAN test pass
- Phase 163 — Clang-tidy gate
- Phase 164 — Doxygen / API docs

This ADR audits each gate's current state and records the v1.0
readiness signal.

## Decision

### Phase 161 — CI workflow

Existing `.github/workflows/ci.yml` covers:

- **Windows 2025** runner: MSVC (`cl.exe` via the `windows` job)
  builds + tests every push.
- **Ubuntu 24.04**: Clang (`clang++ -O0/-O3`) builds + tests.
- **macOS 14**: AppleClang builds + tests.
- **Lavapipe (Mesa)**: Vulkan software ICD for golden-image
  regression on every PR.
- **AMD-RADV** nightly workflow (`.github/workflows/ci-amd-radv.yml`).
- **Bench regression** workflow tracks perf headers.

What's intentionally NOT in CI yet:

- **Clang-cl on Windows**: MSVC is the primary Windows compiler
  per the project standards (CLAUDE.md §6). Adding Clang-cl is a
  v1.1 improvement; MSVC parity is enough for v1.0.

**Verdict:** Phase 161 ✓ GREEN.

### Phase 162 — ASAN / UBSAN

`CMakePresets.json` defines `ninja-base-asan` whose description is
"Address + UndefinedBehavior sanitizer aktif" — the preset wires
**both** `-fsanitize=address` and `-fsanitize=undefined` via the
`CD_SANITIZER=asan` toggle in `CMakeModules/Sanitizers.cmake`.
The CI `sanitizers` job runs this preset on every PR.

A separate `ninja-base-tsan` covers thread-sanitizer.

**Verdict:** Phase 162 ✓ GREEN. (UBSAN is bundled with ASAN by
design — they share the same compile-time toggle and that is the
documented contract in the preset description.)

### Phase 163 — Clang-tidy gate

The CI `tidy` job runs `clang-tidy --warnings-as-errors='*'` on
every C++ file changed by the PR. A `.clang-tidy` config file at
the repo root controls the check set.

What's NOT in CI yet (deliberate):

- **Full-tree nightly tidy**: noted as a TODO in `ci.yml` comments;
  the per-PR-diff gate is enough to keep new code clean, and the
  full-tree variant trips on legacy code that pre-dates the tidy
  config. Deferred to v1.1 with a tidy-config cleanup pass first.

**Verdict:** Phase 163 ✓ GREEN (incremental gate; nightly full-tree
is v1.1).

### Phase 164 — Doxygen / API docs

`.github/workflows/docs.yml` builds Doxygen HTML on every PR and
deploys to GitHub Pages on master push. The Doxyfile is under
`docs/Doxyfile.in`. Header files across the engine carry the
required `@brief` / `@param` / `@return` markup added during the
marathon.

**Verdict:** Phase 164 ✓ GREEN.

## Side improvement

This ship adjusts the marathon summary doc to surface the support
matrix produced by Waves 308-311:

| Subsystem        | v1.0 status                                          |
|------------------|-------------------------------------------------------|
| Vulkan backend   | graphics + compute + RT (primary)                     |
| D3D12 backend    | graphics + compute (secondary; RT deferred to v1.1)   |
| OpenGL backend   | buffer + texture + sampler (partial; v1.1)            |
| PBR lighting     | analytical sky + 3-light + ACES tonemap (IBL: v1.1)   |
| Animation        | cubic-Bezier (skeletal: v1.1)                         |
| Audio            | pre-rendered clip + DSP chain (push-stream: v1.1)     |
| Platform window  | Windows (Win32) — primary                             |
| Cross-platform   | Linux / macOS / mobile: WAVE H scope decision next    |
| CI               | MSVC + Clang + AppleClang + Lavapipe + AMD-RADV       |
| Sanitizers       | ASAN+UBSAN + TSAN                                     |
| Static analysis  | clang-tidy on PR diff, clang-format gate              |
| Docs             | Doxygen → GitHub Pages                                |

## Rejected alternatives

- **Add Clang-cl Windows matrix entry** — duplicates MSVC for
  marginal compiler-portability gain. v1.0 is MSVC-primary on
  Windows; matrix expansion is a v1.1 polish item.
- **Add full-tree clang-tidy nightly job** — requires a
  config-cleanup pass first; deferred.
- **Add Doxygen warnings-as-error** — the workflow currently
  inspects warnings but doesn't fail on them. Tightening this is
  a v1.1 polish item; v1.0 ships with warnings tolerated.

## Consequences

- WAVE G is closed with all four phases marked GREEN.
- v1.0 quality bar: CI covers 3 OSes, 2 compilers (MSVC + Clang),
  ASAN+UBSAN+TSAN, clang-tidy, clang-format, Doxygen — sufficient
  signal to gate v1.0 ship.
