# ADR — v0.47.0 / Wave 175 — Phase 16 close

- Date: 2026-05-24
- Status: Accepted
- Wave: 175
- Tag: v0.47.0 (single tag covering Phase 16 sub-phases A-E)

## Sub-phases shipped

### 16.A — Editor DockBuilder + keyboard mapping
- `ImGui::DockBuilder` builds the default layout on first frame
  (Toolbar top, Scene left, Inspector right, History bottom,
  passthrough center for the viewport). User-resized splits persist
  via imgui.ini.
- `cd::imgui::Context::to_imgui_key` extended to map all letters
  (A-Z), digits (0-9), F1-F12, modifiers (LShift/RShift/LCtrl/
  RCtrl/LAlt/RAlt). The missing letter mapping was the root cause
  of the user-reported broken WASD camera — `IsKeyDown(W)` was
  always false because `AddKeyEvent` was never called with W.
- Camera right-vector sign fix — A/D were inverted; right is now
  `(-forward.z, 0, forward.x)` matching the right-handed Y-up
  convention.

### 16.B — D3D12 descriptor set extensions
- `update_descriptor_set` now handles `kStorageImage` (UAV Texture2D),
  `kStorageBuffer` (raw UAV Buffer), `kCombinedImageSampler` (SRV
  half; sampler half routed to static-sampler fallback), and
  silently skips `kSampler` writes (separate sampler heap is a
  later wave). Cube SRVs + structured UAVs deferred.

### 16.C — `cd::asset::FileWatcher`
- Header-only polling watcher. `watch(path, cb)` adds a file;
  `poll()` checks mtimes per-call and invokes the callback when
  any file's mtime advances. Three unit tests pin the contract
  (fresh-file no-fire, mtime-advance fires, unwatch stops).
- Foundation primitive for the Phase-17 cross-asset hot-reload
  surface (textures / meshes / scenes alongside the existing
  shader hot-reload).

### 16.D — `cd::imgui::profiler_flamegraph`
- Header-only ImGui widget that renders a Tracy-style flame graph
  from a `std::span<const cd::profile::Sample>`. Per-thread lane,
  name-hash color, hover tooltip with duration + start time.
- cd::imgui_backend gains PUBLIC_DEPS cd::profile so any consumer
  can include `cd/imgui/ProfilerView.hpp` and call it inside a
  Begin/End block.

### 16.E — Phase 17 headline pre-staging
- The originally-planned Phase 16 items 16.C (Vulkan RT pipeline),
  16.D (material v2 PBR multi-pass), 16.G (AMD CI) ARE *not*
  abandoned — they're explicitly the headline candidates for
  Phase 17. The Phase 17 plan ADR (wave 176) lists them in
  priority order.
- Reason: those three items together exceed the marathon
  budget that this Phase 16 run could honor while also
  closing 17 + 18. Honest scope cut + transparent
  re-prioritization, not silent dropping.

## Version policy

Per user direction (Wave 167+): version bumped **only at tag
time**. 0.42.0 / 0.43.0 / 0.44.0 / 0.45.0 / 0.46.0 sequential
bumps from earlier phases were replaced with single-bump-at-
close discipline. Phase 16 starts at 0.46.0 and tags at
**v0.47.0**.
