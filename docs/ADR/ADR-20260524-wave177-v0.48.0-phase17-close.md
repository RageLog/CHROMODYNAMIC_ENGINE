# ADR — v0.48.0 / Wave 177 — Phase 17 close

- Date: 2026-05-24
- Status: Accepted
- Wave: 177
- Tag: v0.48.0

## Sub-phases shipped

### 17.A — Vulkan BLAS construction (real impl)
- `VulkanDevice::create_acceleration_structure` override now
  actually allocates VMA AS-storage buffer + creates the
  VkAccelerationStructureKHR via vkCreateAccelerationStructureKHR.
- Computes build sizes via
  `vkGetAccelerationStructureBuildSizesKHR` against the supplied
  triangle geometry list + primitive counts.
- Per-geometry `VkAccelerationStructureGeometryKHR` populated
  with vertex/index device-address (bufferDeviceAddress was
  enabled in Phase 15.E for exactly this).
- `destroy_acceleration_structure` releases the AS handle + VMA
  buffer.
- TLAS path returns kNotImplemented (Phase 18.A).
- Build dispatch (vkCmdBuildAccelerationStructuresKHR on the
  command buffer) deferred to Phase 18.A so the BLAS-build
  primitive + RT pipeline + SBT land coherently.

### 17.B / 17.C / 17.D / 17.F — deferred to Phase 18

Honest scope cut. The Phase 17 plan listed seven items; only
17.A (BLAS create) landed at the implementation level. The
remaining items — RT pipeline + SBT (17.B), material v2 PBR
multi-pass (17.C), OpenGL backend boot (17.D), AMD CI workflow
(17.F) — are the Phase 18 headline. The marathon's ordering
"easy → hard, AI-actionable first" pushes the multi-shader
items deeper into the queue.

### 17.E — Hot-reload registry tick design

`cd::asset::FileWatcher` is the foundation primitive (Phase 16.C).
Phase 17 documents the intended consumer wire-up:
`AssetRegistry::tick(now)` will poll the watcher and route
mtime-advance callbacks back to the per-asset loader's reload
path. The actual code change is a small follow-up in Phase 18
alongside the texture/scene reload tests.

### 17.G — Editor selection-outline + gizmo design ADR

Design note (no code): the selected entity in hello_editor's
viewport will be highlighted by re-drawing it with
`raster.cull = kFront` and a slightly-scaled inflated
model-matrix to produce a flat-color silhouette. The translation
gizmo will be three axis-aligned arrows hit-tested against the
mouse ray. Both are Phase 18 implementation work.
