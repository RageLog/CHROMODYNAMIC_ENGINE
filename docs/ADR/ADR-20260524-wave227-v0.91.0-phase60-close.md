## Bağlam

Phase 60, marathon'un 63. minor release'i. Animation event track +
scene named transform anchor (marker) primitive'leri.

## Karar

### 60.A — `cd/anim/EventTrack.hpp`
Sorted `(t, id)` events + `advance(t_prev, t_now, fn)` window-fire
helper:
- `add(t, id)` — lower_bound sort-on-insert.
- `advance(prev, now, fn)` — events ∈ (prev, now] için fn(id) çağır.
  Half-open from prev, closed at now → animation tick boundary'lerinde
  duplicate fire yok.
- `clear()`, `events()`.

Foot step sound, weapon swing damage check, particle spawn cue —
animasyon-driven gameplay callback'lerinin temel primitive'i.

### 60.B — `cd/scene/Marker.hpp`
Named transform anchor:
- `MarkerSet.add(name, transform)` — name_hash key, overwrite-on-add.
- `find(name)` / `find_by_hash(h)` — lookup.
- `remove(name)`, `size()`, `all()` view.

Spawn point, cutscene focus, skeletal weapon attach slot için ortak
veri tipi. `NameRegistry`'in (Phase 45) entity-bound counterpart'ı —
bu transform-bound.

## Reddedilen alternatifler

- **EventTrack için looping/wrap support**: caller `advance(t_prev,
  t_now)` window'unu wrap-around için iki çağrıya bölebilir
  (prev→clip_end + clip_start→now). Primitive linear.
- **MarkerSet ↔ NameRegistry birleştirmek**: Entity ID ile transform
  tipinde değer farklı; ayrı tip API ergonomisini artırır.
