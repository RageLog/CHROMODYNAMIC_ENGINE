### 48.B — `cd/concurrency/Barrier.hpp`
`std::barrier` wrapper. Latch tek-kullanımlık, Barrier reusable:
- `arrive_and_wait()` N thread arrive olunca tümünü unblock + sayacı
  reset.
- `count()` getter.

Game-loop sync points (N worker thread X aşamasını bitirsin sonra
hep birlikte X+1'e geçsin) ve frame-level pipeline rendezvous için.
