# ADR-20260524 wave199 — v0.62.0 Phase 31 close

## Bağlam

Phase 31, anim ve input katmanlarına sıradaki "olmadan da çalışır ama
varlığı kaliteli editör hissi verir" primitive'lerini ekler.

## Karar

### 31.A — `cd/anim/AdditiveBlend.hpp`
Üst-vücut overlay / aim / lean / breathe gibi additive layer
animasyonları için: `out = base + weight·delta` per-joint, rotation
için `nlerp(identity, delta, weight)` kullanılır (Unreal UE5 layered-blend
formülünün CHROMA muadili). Bu, `BlendTree2`'nin LERP-paralel ucudur:
BlendTree2 iki tam pose'u harmanlar, AdditiveBlend bir delta'yı baz
üzerine sürer.

Quaternion arc-shortest yönü `sign` testi ile seçildi; degenerate-zero
rotation için `len2 > 0` koruması var. `weight` `[0,1]` clamp.

### 31.B — `cd/input/DoubleClick.hpp`
Çift-tık / üç-tık dedektörü. Caller monotonic saat değeri verir
(saniye); threshold içinde gelen ardışık tıklar sayacı arttırır,
threshold aşımı tek tıka sıfırlar. Default 0.4s — Windows
GetDoubleClickTime() ortalaması.

Platforma bağlı saat almıyoruz — test deterministic olsun diye.
Editor frame loop bunu kendi `monotonic_time()`'ından besleyecek.

## Test

- AdditiveBlend: ZeroWeightReturnsBaseUnchanged, FullWeightAddsDeltaPosition,
  SizeMismatchRejected — 3 case.
- DoubleClick: FirstClickReturnsOne, TwoClicksWithinThresholdReturnTwo,
  GapBeyondThresholdResetsToOne, TripleClickReachesThree, ResetZeroesCounter — 5 case.

`test_input.cpp`'nin anonymous-namespace bloğu yeniden çerçevelendi:
include + TEST'ler hep aynı anon ns içinde durur (clang `-Wall -Werror`
altında ambiguity hatası vermesin diye).

`ctest --preset ninja-debug` → **58/58 PASS**.

## Reddedilen alternatifler

- **DoubleClick'i platform clock'a bağlamak**: `<chrono>::steady_clock`
  kolay ama test edilemez. Caller-supplied time daha temiz.
- **AdditiveBlend için SLERP**: weight=1 doğru sonuç verir ama küçük
  weight değerlerinde nlerp_to_identity zaten yeterince yakın ve
  ~2× hızlı (skinning hot path).
- **Multi-stage gesture FSM**: drag/swipe/pinch tek bir header'a
  sığmaz; ileride `cd::input::Gestures` ayrı modül olur.
