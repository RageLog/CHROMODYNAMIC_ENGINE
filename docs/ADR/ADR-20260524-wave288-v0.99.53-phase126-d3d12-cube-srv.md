# ADR-20260524 / Wave 288 / v0.99.53 / Phase 126 — D3D12 cube-map view

## Status
Accepted — 2026-05-24

## Context

Phase 124 shipped `create_texture_view` for 2D textures; Phase 122's
parity audit ranked the cube-map view (needed for IBL on D3D12) as
priority #3 (1-2 hours effort). The same audit also flagged the
`update_descriptor_set` "cube SRV — coming in a follow-up" branch.

## Decision

Extend the Phase 124 path to honour `TextureType::kCube`:

1. **`create_texture_view`** — accept `kCube` alongside `k2D`. When
   building the SRV use `D3D12_SRV_DIMENSION_TEXTURECUBE` +
   `srv.TextureCube.MostDetailedMip / MipLevels`. UAV cube view
   maps to `D3D12_UAV_DIMENSION_TEXTURE2DARRAY` with `ArraySize = 6`
   (D3D12 has no dedicated cube-UAV dimension).
2. **`TextureViewRecord`** gains an `is_cube` bool so
   `update_descriptor_set` knows which `ViewDimension` to write at
   descriptor-table fill time.
3. **`update_descriptor_set`** — the existing `kSampledImage` and
   `kCombinedImageSampler` branches now consult
   `view_it->second.is_cube` and pick `TEXTURECUBE` vs `TEXTURE2D`.
   The descriptor type itself doesn't gain a cube variant (no
   separate enum); the view dimension carries that information.

## Rejected alternatives

- **Add `kCombinedImageSamplerCube` to `DescriptorType`.** Would
  bifurcate the consumer code path. Vulkan's
  `VkDescriptorImageInfo` doesn't distinguish either; the dimension
  is on the `VkImageView`.
- **Allocate a separate cube-only descriptor heap.** Pointless —
  cube SRVs occupy the same `CBV_SRV_UAV` heap slot as 2D SRVs.
- **Add per-face slicing to `TextureViewDesc`.** Out of scope —
  IBL prefiltering will want per-mip-per-face views eventually
  but the current pass can use a single full-mip cube view per
  texture.

## Consequences

- D3D12 IBL path now has the descriptor it needs to bind a cube
  texture into a hit shader / forward fragment shader.
- Phase 122 audit's "cube SRV pending follow-up" remark cleared.
- D3D12 `kNotImplemented` site count: 4 → 4 (no new stubs;
  existing branches stayed inside their default case).

## Validation

```
cmake --build --preset llvm-win-debug --target cd_rhi_d3d12
```

D3D12 backend builds clean. Behavioural test pending until a
sample exercises a cube texture on the DX12 path (hello_pbr is
Vulkan-only at present).
