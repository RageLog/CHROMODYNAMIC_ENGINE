## Karar

### 39.A — `cd/physics/RaySphere.hpp`
Ray + Sphere için klasik kuadratik diskriminant çözümü:
- `a = D·D` (caller direction'u normalize etmek zorunda değil)
- `b = 2·(O-C)·D`
- `c = (O-C)·(O-C) - r²`
- `Δ = b² - 4ac`

İki kök kontrol edilir: t0 ≥ 0 → entry hit; t0 < 0 ve t1 ≥ 0 → origin
küresin içinde (t=0 dönülür); ikisi de negatif → küre arkada (nullopt).
Zero-length direction (a < 1e-12) defansif olarak nullopt.

Picking, projectile collision, audio-occlusion ray-cast için.

### 39.B — `cd/math/AngleUnits.hpp` + literals
`to_radians(deg)` / `to_degrees(rad)` constexpr free functions +
`namespace cd::math::literals` içinde `operator""_deg` ve
`operator""_rad`:

```cpp
using namespace cd::math::literals;
const float yaw = 45.0_deg;   // radyan
const float fov = 60_deg;     // integer literal
```

Tüm engine math radyan; UI / scene file degree olabilir — bu helper
geçişi tek nokta + read-as-physics-notation yapar.

## Reddedilen alternatifler

- **Geometric solve (project + perpendicular distance)**: literatürde
  bilinen ama numeric stability açısından discriminant ile aynı; klasik
  form okumayı kolaylaştırır.
- **UDL'leri `cd::math` ad alanında doğrudan açmak**: `using namespace
  cd::math;` programı patlatabilir. `namespace literals` sub-namespace
  Standard library'nin de uyguladığı disiplinli pattern.
