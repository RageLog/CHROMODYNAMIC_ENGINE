# ADR — v0.45.0 / Wave 169 — Phase 15.D HRTF + reverb DSP nodes

- Date: 2026-05-24
- Status: Accepted
- Wave: 169
- Predecessor: Wave 168 (v0.44.0 DXC/SM6)

## Context

Phase 14.F shipped the structural DspGraph (Gain + Biquad LP/HP).
The Phase 15.D candidate wraps the existing analytical HRTF
synthesizer (Wave 96) as a graph node, plus adds a small FIR
"early reflections" reverb. Perceptual tuning still needs a
human ear — the marathon ships the math + structure.

## Decision

Scope: two new IDspNode subclasses in cd::audio::DspGraph,
five new unit tests pinning their math.

### What landed

- **`cd::audio::HRTFNode`** wrapping `HrtfConvolver`. Mono →
  stereo convolution; chain-style in-place `process()` is a
  passthrough (the channel-count change can't be expressed
  in the chain contract), and a dedicated `render(mono_in,
  stereo_out)` method drives the actual convolution.
  `set_pose(listener, source_world_pos, sample_rate)`
  refreshes coefficients via `synthesize_hrtf`.
- **`cd::audio::FirReverbNode`** — 32-tap direct-form FIR
  with a hard-coded "small room" early-reflection IR:
  direct (1.0), reflections at tap 7 (0.45), 14 (0.30),
  23 (0.18), 31 (0.10). Wet/dry mix scalar (default 0.35).
  Mono → mono in place. No diffuse tail — that's a Phase-16
  candidate.
- Five new tests in `cd_test_audio`:
  - `HRTFNode.MonoInputProducesStereoOutput`
  - `HRTFNode.InPlaceProcessIsNoOp`
  - `FirReverb.DirectTapIsUnchangedAtZeroWet`
  - `FirReverb.ImpulseProducesEarlyReflections`
  - `FirReverb.ResetClearsHistory`
- DspGraph.hpp now includes AnalyticalHRTF.hpp and
  Positional.hpp transitively.

### What deliberately did NOT land

- **Late-tail diffuse reverb** (Schroeder / FDN / convolution
  with a measured IR). Phase-16 candidate.
- **HRTF database support** (CIPIC / SADIE). The analytical
  shape is good enough for "is the sound on the left or the
  right" but not for full-3D localization. Database wave
  needs licence-aware vendoring.
- **Per-source DspGraph routing.** The Positional engine
  side already handles per-voice; the next polish is wiring
  HRTFNode into PositionalSource so callers get HRTF "for
  free" when they spatialize.

## Consequences

- cd_test_audio grows from 47 to 52 internal cases.
- DspGraph public surface gains two terminal-node options.
- Phase 15.E (Vulkan RT pipeline) opens next.
