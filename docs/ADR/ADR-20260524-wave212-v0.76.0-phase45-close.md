## Bağlam

Phase 45, marathon'un 48. minor release'i. Input katmanına modifier-aware
chord matcher ve scene katmanına name ↔ entity registry eklendi.

## Karar

### 45.A — `cd/input/KeyChord.hpp`
Bitmask Mod enum (`kCtrl | kShift | kAlt`), `KeyChord { trigger, mods }`
struct, `matches(chord, evt, state)` Y/N kontrolü. L/R modifier
varyantları birleştirildi: `kLCtrl` veya `kRCtrl` → `Mod::kCtrl`.

Exact-mod-match (Ctrl+S, Ctrl+Shift+S basarken Ctrl+S **fire etmez**)
— editor shortcut'larında doğru davranış.

`current_mods(state)` helper yardımcı; testlerden de doğrudan
çağrılabilir.

### 45.B — `cd/scene/NameRegistry.hpp`
FNV-1a 32-bit `name_hash(view)` + iki-yön unordered_map:
- string → Entity (`find(name)`)
- Entity.id → string (`name_of(entity)`)
- hash → Entity (`find_by_hash(h)`)
- `bind` / `unbind` ekleme/silme; rebind eskisini overwrite eder.

Storage Entity::id (uint32) üzerinden — generation drop edilir
(scene-scope binding; caller entity destroy'ında `unbind`
yapmalı).

### Test hygiene (tekrar pekiştirme)
Anon-namespace-include trap üçüncü kez bu marathonda yakalandı.
`KeyChord.hpp` test_input.cpp'nin anon ns içinde include edilince
`namespace cd::input` nested açıldı ve outer-cd::input::KeyCode
görünmez oldu. Final çözüm: tüm cd/input/* include'ları file-top'a
çıkarıldı, anon namespace içinde include kalmadı.

Bu pattern artık marathon convention: **anon namespace içinde new
header include ETME — file-top'a çıkar, tests içeride kalsın**.
