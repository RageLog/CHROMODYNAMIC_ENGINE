# ADR-20260524 wave213 — v0.77.0 Phase 46 close

## Bağlam

Phase 46, marathon'un 49. minor release'i. Physics ailesine
capsule-sphere overlap testi ve asset alt-sistemine priority-driven
streaming queue primitive'i eklendi.

## Karar

### 46.A — `cd/physics/CapsuleSphere.hpp`
O(1) overlap testi: küre merkezinin kapsül segmentine uzaklığı ≤
(kapsül radius + küre radius). Mevcut `distance_point_segment`
yardımcısı kullanılır (Capsule.hpp içinde).

Symmetric overload (`intersects(s, c)` → `intersects(c, s)`) caller
ergonomics için.

Karakter capsule vs trigger sphere, projectile sphere vs hitbox
capsule, AI LoS cone simplified to capsule kullanımları için.

### 46.B — `cd/asset/StreamRequest.hpp`
Streaming için priority queue:
- `StreamRequest { id, priority, deadline_frame }`.
- `StreamState`: Pending / Inflight / Complete / Failed.
- `StreamQueue.push(r)` priority-heap'e ekler, state Pending.
- `pop_top()` en-urgent çekildi, state Inflight.
- `mark_complete` / `mark_failed` state günceller.
- `state_of(id)` lookup.

Heap comparator priority < olarak verildi (std::priority_queue benzeri
max-heap davranışı). Open-world texture/audio stream pipeline'ı için.

## Test

  TouchingSurfaces, SymmetricSphereCapsule — 4 case.
- StreamQueue: EmptyOnConstruction, PopReturnsHighestPriorityFirst,

`ctest --preset ninja-debug` → **58/58 PASS**.

## Reddedilen alternatifler

- **GJK distance**: Capsule-Sphere closed-form çözüm, GJK overhead'ine
  gerek yok.
- **StreamRequest için Boost.MultiIndex**: priority + deadline + id
  triple index güzel olur, ancak Boost dep manifest mode'a karşı
  şikayet eder. std::vector + unordered_map yeterli.
