# ADR-20260524 wave201 — v0.65.0 Phase 34 close

## Bağlam

Phase 34, rhi'a iyi bilinen blend-state preset'leri ve core'a tek-word
küçük bitset helper'ı ekler.

## Karar

### 34.A — `cd/rhi/BlendPresets.hpp`
4 free-function: `blend_opaque()`, `blend_alpha()`, `blend_premultiplied()`,
`blend_additive()`. Her biri tam doldurulmuş `BlendAttachmentState`
döner; PSO-build sitelerinin elle src/dst/op tablo yazmaktan kurtarır.

UI sprite path = alpha, particle = additive, decal/atlas = premultiplied,
opaque mesh = opaque (blend_enable=false).

### 34.B — `cd/core/Bitset.hpp`
`std::bitset` yetersiz olduğu için fixed-N bitset:
- `find_first_set()` (sentinel N if empty)
- `for_each_set(fn)` — std::countr_zero ile word başına bit iterasyonu
- `count()`, `any()`, `none()`, `set/clear/test/reset`

Render mask, asset flag set, ECS archetype layer için altyapı. Word
büyüklüğü 64-bit; N → ceil(N/64) word array.

### Subtle bug fix — anonymous namespace include placement
`test_rhi.cpp` ve `test_input.cpp` (Phase 31) anon namespace içine
`#include <header>` yazmak yeni header'ın `namespace cd::rhi` declaration'unu
**iç içe** geçmiş `::{anon}::cd::rhi`'a açıyor — Descriptors.hpp'nin
`::cd::rhi::BlendAttachmentState` semboline ulaşamıyor. Fix: include'u
file-top'a taşımak (TU'nun outer scope'unda), tests'ler anon namespace
içinde kalsın ama header açılış scope'u global olsun.

Bu davranış C++ spec'ine uygun (anon ns içinde nested ns aç-kapamayı
diğer scope-larla karıştırma); subagent'lar için lesson learned.

## Reddedilen alternatifler

- **`struct BlendPresets` static-only**: clang-cl namespace lookup
  içinde tutarsız sonuç verdi (header-inside-anon-ns sorunundan ayrı bir
  parse problem alanı); free function temiz.
- **dynamic_bitset**: heap allocate gerekiyor, hot path için ucuz değil.
  Fixed N kapsam yeterli (render-pass masks ≤ 32 attachment, archetype
  layer ≤ 256 component bit).
