# ADR-20260522 — Wave 36: v0.5.0 release tag

## Bağlam

Phase 5 marathon ikinci yarısı (Waves 28-35) tamamlandı. v0.4.0
(Phase 5 first cycle, Waves 23-27) sonrası eklenen 9 wave engine'i
multiplexed networking, golden image diff, cross-platform audio
parity ve hot-reload yeteneği ile genişletti. Phase 5 closure +
Phase 6 routing ADR'si (ADR-20260522-phase6-routing) bu tag'le
birlikte iniyor.

## Karar

`v0.5.0` git tag'i atılır. Phase 5 marathon kapanışı bu sürümün
mesajıdır. Pre-release değil — 4/4 compiler × 54/54 ctest green
(Windows host); macOS/Linux runtime backend'leri stub durumda ama
API parity tam (caller'lar `make_native_audio_backend()` ile uniform
fallback alır).

Tag dev branch HEAD'ine atılır; master'a merge kullanıcı izniyle
ayrı PR olarak yapılır (v0.4.0 modelinin tekrarı).

## Bu sürümde olanlar (delta v0.4.0 → v0.5.0)

### Yeni Phase 5 waves (28-35)

| Wave | Çıktı |
|---|---|
| Wave 28 | `cd::asset_pak` iyileştirme — GCC `-Wuseless-cast` temizliği, 64-bit invariant doğrulama |
| Wave 29 | `cd::asset_gltf` skinning — JOINTS_0/WEIGHTS_0 attribute, GltfSkin + inverse-bind matrices |
| Wave 30 | `cd::render::AsyncSubmitN` — N-deep SPSC render thread pipeline (ring queue + bounded backpressure) |
| Wave 31 | `cd::ibl` — CPU BRDF LUT bake (Hammersley + GGX importance sampling), header-only |
| Wave 32 | `cd::net::ChannelMux` — typed multi-channel multiplexer (reliable-ordered + unreliable-unordered) |
| Wave 33 | `cd::imgdiff` — golden image pixel diff (RMSE, PSNR, tolerance, highlight overlay) |
| Wave 34 | `cd::audio` cross-platform parity — CoreAudio/ALSA stubs + `make_native_audio_backend()` |
| Wave 35 | `cd::plugin::HotReloader` — poll-driven hot reload, load-first/then-unload safety |

## Reddedilen alternatifler

- **`v1.0.0` tag:** Phase 6 kümeleri (Forward+/mobile RHI/scripting)
  hâlâ açık. v1.0 = production-ready iddiası için erken.
- **`v0.5.0-beta` veya `-rc1`:** Tag policy v0.X.0 baseline'larında
  modifier kullanmıyor (v0.2.0, v0.3.0, v0.4.0 hepsi düz baseline).
  Tutarlılık için `v0.5.0` düz.
- **Tag'i master'a atmak:** Mevcut workflow `dev` branch çalışıyor;
  master'a merge ayrı bir adım (PR önerisi).

## Sonuçlar

`v0.5.0` annotated git tag, dev HEAD üzerine atılır. Mesaj bu ADR'yi
özet olarak gömer. Phase 5 resmen kapanır; sonraki iş Phase 6 routing
ADR'sinden seçim ile başlar.

Master'a merge stratejisi, CHANGELOG.md formalizasyonu ve GitHub
Release artifact'leri v0.4.0 ADR'sindeki "açık sorular" bölümünden
takip edilen iş — bu sürümde de aynı sırada açık.

## Açık sorular

* **Phase 6 önceliği:** Render (Forward+ + mobile) vs networking
  (retransmit + real UDP) vs plugin (native watcher + symbol diff).
  Kullanıcı karar verecek; bu sürüm sadece "kümeler hazır" diyor.
* **CI runner expansion:** macOS / Linux audio için fiziksel host
  gerekli. v0.5.0 sonrası bunu çözmek Phase 6 ALSA / CoreAudio
  implementasyonlarının prereq'i.
