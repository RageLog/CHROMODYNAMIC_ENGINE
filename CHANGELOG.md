# CHROMODYNAMIC Changelog

All notable changes to this project are documented here. The format
follows [Conventional Commits](https://www.conventionalcommits.org/);
release section bodies are generated by `cd_changelog_gen` from the
commit log between adjacent tags.

`docs/ADR/ADR-...-vX.Y.0-release.md` file.
