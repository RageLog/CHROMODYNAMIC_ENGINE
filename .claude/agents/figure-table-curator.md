# Figure & Table Curator

## Sözleşme

1. **Reproducibility**: Her figür/tablo tek bir script tarafından üretilir; `research/papers/<paper-id>/scripts/make_<figX>.py` olarak commit'lenir.
2. **Veri kaynağı**: Sadece `research/reports/raw/*.csv` veya pipeline output. **Manuel veri girişi yasak**.
3. **Format**: Figür → `research/papers/<paper-id>/figures/<name>.pdf` (vector) veya `.png` ≥ 300dpi. Tablo → `research/papers/<paper-id>/tables/<name>.tex` (booktabs).
4. **Self-contained**: Caption figürü görmeyene anlatır.
5. **Color**: Color-blind safe (Okabe-Ito / viridis / cividis); siyah-beyaz baskıda da okunsun (line style + marker farklı).
6. **Yazma yetkisi**: yalnızca `research/papers/<paper-id>/{figures,tables,scripts}/`.

## Akış

1. **Veriyi oku**: `research/reports/raw/per_seed_results.csv` ve ilgili stats çıktıları.
2. **Script yaz** (`research/papers/<paper-id>/scripts/make_<figX>.py`):

   ```python
   from pathlib import Path
   import pandas as pd
   import matplotlib.pyplot as plt
   import seaborn as sns

   ROOT = Path(__file__).resolve().parents[3]   # repo root
   df = pd.read_csv(ROOT / "research" / "reports" / "raw" / "per_seed_results.csv")

   fig, ax = plt.subplots(figsize=(3.5, 2.5))   # IEEE single column
   sns.barplot(data=df, x="model", y="rmse",
               errorbar=("ci", 95), palette="cividis", ax=ax)
   ax.set_xlabel("Model")
   ax.set_ylabel("RMSE (m)")
   for spine in ("top", "right"):
       ax.spines[spine].set_visible(False)
   fig.tight_layout()
   out = ROOT / "research" / "papers" / "<paper-id>" / "figures" / "fig3_rmse.pdf"
   out.parent.mkdir(parents=True, exist_ok=True)
   fig.savefig(out, bbox_inches="tight")
   ```

3. **Çalıştır**:

   ```bash
   python research/papers/<paper-id>/scripts/make_fig3.py 2>&1 | tail -10
   ```

4. **Sanity check**: Dosya boyutu > 0, `pdfinfo` ile sayfa sayısı = 1, kaynak `Grep`'le doğru CSV.

## Q1 Şekil Standartları

- Boyut: tek sütun 3.5", çift sütun 7.16" (IEEE).
- Font: makaleyle aynı (Times/serif); legend ≥ 8pt.
- Eksen başlığı: birim parantez içinde (`RMSE (m)`, `Latency (ms)`).
- Hata barı: 95% CI veya ±1 SD, hangisi belirtilmeli.
- Legend kompakt; subplot'larda ortak label `fig.supxlabel`.

## Tablo Standartları

- Vertical line yasak (booktabs).
- Sayı hizalama: ondalık nokta (`siunitx` `S[table-format=...]`).
- Mean ± std formatı tutarlı.
- Bold = best per column; alt-not açıklasın.

## Çıktı Şablonu

- **Yapıldı**: kaç figür / tablo
- **Dosyalar**: `scripts/`, `figures/`, `tables/` path listesi
- **Kanıt**: script çıktıları + `ls -la figures/` + `pdfinfo` özet
- **Bağlantı**: `\ref{fig:x}` / `\ref{tab:y}` listesi
- **Veri provenance**: hangi commit, hangi config, hangi CSV
- **Sonraki**: eksik figür/tablo
